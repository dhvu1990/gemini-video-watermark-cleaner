# v1.0.61 — Structured Ring Diagnostics Runtime Integration

Date: 2026-08-18

## Goal
Wire the structured-ring diagnostic summary introduced in v1.0.60 into the actual dual-ring runtime output before making any further behavior/strength tuning decisions.

## Why this step is needed
v1.0.60 added `summarizeStructuredRingDiagnostics()` and unit coverage, but the helper was not yet attached to the runtime result returned by `applyDualRingLumaFinish()`. Without runtime integration, later UI/log/telemetry cannot consume the same normalized evidence that tests use.

## Logic
- Import `summarizeStructuredRingDiagnostics()` into `dualRingFinish.js`.
- After the structured/smooth decision and all cleanup stages have completed, create one normalized `structuredRingDiagnostics` summary from the final `structuredRing` result.
- Use `selected.width * selected.height` as the normalization denominator for aligned sample density.
- Expose the same summary at three runtime locations:
  - top-level result: `result.structuredRingDiagnostics`
  - `result.dualRingFinish.structuredRingDiagnostics`
  - `result.smoothBackground.structuredRingDiagnostics`
- The summary is computed after pixel processing and is read-only with respect to selection/acceptance decisions.

## Safety / behavior neutrality
This version intentionally does not change:
- smooth vs structured mode selection
- structured-ring attempt thresholds
- structured-ring strength
- salvage thresholds/strength
- consensus/shape-ghost/center-seam/local-tone/outer-halo logic
- temporal atlas behavior
- calibration scoring
- any pixel blend or restoration formula

The only runtime change is additional diagnostic metadata in the returned object.

## Regression test
New test: `tests/structuredRingDiagnosticsRuntime.test.mjs`

It forces the structured runtime path (`smoothBackground:false`) and verifies:
- `structuredRingDiagnostics` exists in the real `applyDualRingLumaFinish()` output;
- the same summary object is surfaced in top-level, `dualRingFinish`, and `smoothBackground` diagnostics;
- enabled/attempted/accepted state mirrors the underlying structured-ring result;
- aligned sample count comes from `structuredRing.alignedBefore.samples`;
- normalized sample density stays in [0,1].
