## First CI attempt - Run #962

Result: failed at `npm test` after `npm run check` passed. Build was skipped because the test stage failed.

The only failing test was:

`strong real boundary through the footprint remains guarded instead of being painted flat`

Observed test diagnostic:

- left mean luma: approximately 0
- right mean luma: approximately 4.8
- `darkUnderflowGuard.attempted`: false
- measured underflow pixels: 0

### Diagnosis

The test combined two separate responsibilities:

1. deliberately over-gaining `inverseAlphaRestore()` strongly enough to collapse the synthetic boundary itself;
2. trying to verify that `darkUnderflowGuard` preserved that boundary.

Because clean-anchor predictions across the artificial high-contrast boundary intentionally disagree, the guard correctly rejected that geometry as an underflow-recovery target and did not attempt correction. The test therefore did not isolate the scene-boundary protection behavior it claimed to validate.

This was a test-design problem, not evidence that the production underflow gates were too strict.

### Fix

The regression was rewritten to test `applyDarkUnderflowGuard()` directly on a controlled synthetic state with:

- a dark collapsed left region;
- a substantially brighter right region;
- a real boundary crossing the watermark footprint;
- enough contrast to verify that the guard does not flatten the scene boundary.

No production thresholds, scene-edge gates, acceptance ratios, or blend limits were loosened to make CI pass.
