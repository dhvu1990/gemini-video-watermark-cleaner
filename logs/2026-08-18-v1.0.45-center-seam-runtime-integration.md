# v1.0.45 — Center-seam runtime integration

## Context
v1.0.44 merged the standalone guarded center-seam suppression module after CI run #519 passed. Real cleaned-preview samples still show a narrow vertical residual through the Gemini diamond on some smooth and semi-structured backgrounds.

## Goal
Wire the already-tested `centerSeamSuppress.js` module into the real structured cleanup runtime without changing the smooth-background rebuild path or globally increasing cleanup strength.

## Runtime order
The structured path now finishes in this order:

1. structured consensus repair
2. structured ring suppression
3. near-miss micro salvage when eligible
4. shape ghost suppression
5. center-seam suppression

Center seam therefore runs only after the broader ring/shape passes have had a chance to remove footprint residuals.

## Implementation
Updated `src/video/structuredRingSuppress.js`:

- imports `applyCenterSeamSuppression`;
- adds `finishWithCenterSeam()` with an explicit `centerSeam: false` opt-out;
- runs center-seam finishing both when ring thresholds skip the primary ring pass and after primary/salvage + shape-ghost finishing;
- exposes full `centerSeam` diagnostics under `structuredRing`;
- extends `acceptedMode` with `+center-seam` only when the seam candidate is accepted;
- includes center-seam acceptance in the structured result acceptance state.

The center-seam module keeps its original try/measure/accept safety gates. Runtime wiring does not bypass any residual checks.

## Safety design
This change intentionally does not:

- run center seam on the smooth-rebuild branch;
- increase structured ring strength;
- widen the center seam mask;
- disable the vertical-scene-structure guard;
- force acceptance when seam residual does not improve.

## Tests
Added `tests/centerSeamRuntimeIntegration.test.mjs` covering:

- structured runtime exposes center-seam diagnostics after earlier structured finishing stages;
- accepted center-seam candidates are reflected in `acceptedMode`;
- the runtime can explicitly disable center-seam finishing.

Existing standalone center-seam tests continue to cover smooth synthetic seam reduction, genuine vertical scene edge protection, and invalid alpha geometry.
