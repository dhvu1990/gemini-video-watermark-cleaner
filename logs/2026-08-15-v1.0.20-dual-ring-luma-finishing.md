# v1.0.20 — Dual-ring luma edge finishing

Date: 2026-08-15

## Objective

Refine the last visible Gemini diamond outline after v1.0.19 while preserving the recovered texture inside the watermark footprint.

## Real-video evidence from v1.0.19

The validation sample showed that the remaining artifact is dominated by luminance rather than color:

- Final total residual: 1.446
- Final luma residual: 2.440
- Final chroma residual: 0.836
- Calibration edge residual: 24.335
- Low-body residual: 0.000
- High-body residual: 17.962

Visual inspection confirmed that the core texture was already good and that the remaining defect was mainly a thin dark/bright edge around the Gemini diamond.

## Design decision

Do not increase Body gain, global blur, atlas strength, or chroma correction. Instead, add a new final pass dedicated to luminance on two separate edge bands.

### Inner ring

The inner ring lies immediately inside the calibrated alpha edge. It is blended conservatively because this region is close to recovered core texture.

### Outer ring

The outer ring lies on the low-alpha side near clean background. It receives stronger luma correction because this is where the visible ghost outline is most obvious.

### Corner/tip weighting

The four sharp Gemini tips are weighted slightly higher than ordinary edge pixels. The boost is bounded to avoid creating a soft or melted tip.

## Implementation

New module: `src/video/dualRingFinish.js`

Main exported functions:

- `buildDualRingMask(alphaMap, width, height)`
- `measureDualRingResidual(image, alphaMap)`
- `applyDualRingLumaFinish(image, alphaMap, options)`

The pass uses the calibrated alpha gradient to estimate the local edge normal. It samples an exterior clean-background anchor and an interior restored anchor, predicts the expected luminance across the edge, and changes only luminance by adding an equal RGB delta. This intentionally preserves the chroma that v1.0.19 already cleaned well.

Structure protection reduces the correction when the two anchors disagree strongly, which indicates a real scene edge rather than watermark residue.

The correction is bounded by:

- low maximum blend
- maximum luminance delta
- high-alpha core suppression
- residual gate
- structure disagreement guard

## Pipeline position

The v1.0.20 sequence is:

1. inverse alpha restore
2. edge polish
3. padded texture repair
4. temporal / multi-frame atlas when useful
5. normal-direction edge bridge
6. micro edge finish
7. adaptive quadrant chroma finish
8. **dual-ring luma finish**
9. temporal correction stabilization
10. MP4 export

The same dual-ring step runs in both the auto-detection cleaned preview and full-video export.

## Diagnostics

The dual-ring module records:

- before total residual
- before inner residual
- before outer residual
- before corner residual
- after total residual
- after inner residual
- after outer residual
- after corner residual
- actual improvement ratio
- corrected pixel count
- mean absolute luminance delta

This also fixes the conceptual problem in the previous `Final improvement` metric by defining improvement directly from the residual immediately before the dual-ring pass versus immediately after it.

## Export metadata

Export metadata is bumped to `1.0.20` and records:

- `dualRingLumaFinish: true`
- number of frames where the dual-ring pass changed pixels
- peak corrected pixel count
- mean dual-ring residual improvement

The old stale engine metadata version (`1.0.17`) is corrected to `1.0.20` in this release.

## Regression tests

New tests in `tests/dualRingFinish.test.mjs` require:

1. total dual-ring residual decreases on a synthetic thin diamond halo;
2. ring pixels move closer to the clean reference;
3. high-alpha core changes by less than one intensity level on average;
4. corner/tip weighting is stronger at the diamond tips than at the protected center.

`npm run check` now also syntax-checks `src/video/dualRingFinish.js`.
