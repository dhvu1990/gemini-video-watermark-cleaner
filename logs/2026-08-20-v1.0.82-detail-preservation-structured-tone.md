# v1.0.82 — Scene detail preservation + faint structured residual + local tone footprint

## User-reported regression set

This release is driven by the current real-video comparison set, with three explicit priorities:

1. **scene5** — the smooth-background branch removes the visible watermark but over-reconstructs the ROI and destroys real underlying scene detail. This is a quality regression and must be prevented even when the residual score improves.
2. **scene6 / scene1** — structured-background results still retain a faint shape-correlated watermark residual. The target is a smaller residual without broad repainting or streak creation.
3. **scene7 / scene3** — cleanup is broadly successful but the repaired footprint can retain a small local luminance/tone mismatch. The target is a more spatially tapered tone correction, especially near the footprint feather.

The guiding rule for v1.0.82 is **preservation before aggressiveness**: a candidate that numerically removes more watermark evidence is not accepted if it erases independent scene detail or broadly shifts surrounding tone.

## Root-cause analysis

### scene5 — smooth rebuild overreach

The v1.0.81 smooth-background reconstruction can run at nearly full replacement strength (`0.995`), with a four-pixel dilation and a transition smoothing pass. Classification uses exterior smoothness plus a core-structure diagnostic, but the final reconstruction previously had no post-candidate comparison measuring whether independent scene edges/texture inside the watermark footprint survived.

A dark or low-contrast scene can therefore look smooth enough to the classifier even when meaningful low-amplitude scene detail exists below the overlay. The surface model then explains that detail away and produces a visually flat patch.

The optional near-empty hard suppression can compound the problem because it performs two stronger smooth reconstructions with larger dilation. Its previous acceptance gate was residual-based rather than detail-retention-based.

### scene6 / scene1 — faint coherent structured residual

The evidence-gated structured refinement was intentionally conservative. Its defaults required relatively strong per-pixel residual, shape alignment and neighboring residual magnitude. This was effective at avoiding repainting, but can miss a low-amplitude residual that is continuous along the Gemini footprint.

For v1.0.82 the solution is not to globally increase the structured ring pass. Instead, the shape-coherent micro pass is made slightly more sensitive while retaining two-sided anchor, tangent coherence, bounded luma delta and downstream residual safety behavior.

### scene7 / scene3 — local tone footprint

The local tone matcher previously used a minimum alpha-weight floor and a single robust global luminance shift across accepted footprint pixels. That can make the correction less spatially selective at the feather boundary and less responsive to a small local offset inside the stronger footprint.

v1.0.82 removes the broad alpha-weight floor, uses a weighted median tone estimate and mixes a bounded per-pixel local correction into the robust global correction only where the residual sign agrees.

## Implementation

### 1. Smooth-background scene-detail preservation guard

File: `src/video/smoothBackground.js`

Added `measureProtectedSceneDetail()`.

The metric operates inside the watermark footprint and measures:

- local luma gradient energy;
- local Laplacian/high-frequency energy;
- edge density.

To avoid treating the watermark itself as scene detail, image gradients aligned with the alpha-map gradient are strongly downweighted. The retained signal is therefore biased toward structure that is independent from the known watermark shape.

Added `evaluateSmoothDetailPreservation()` with conservative default retention gates:

- gradient retention: **>= 0.62**;
- Laplacian retention: **>= 0.58**;
- edge retention: **>= 0.55** when meaningful edge evidence exists.

The guard is only active when the source footprint contains enough non-watermark detail evidence. Ordinary truly smooth gradients therefore continue through the established reconstruction path.

`applySmoothBackgroundReconstruction()` now follows a three-stage policy:

1. render the normal requested smooth candidate;
2. if meaningful scene detail exists and the full candidate loses too much of it, try one conservative fallback;
3. if the fallback still fails detail preservation, return the original input unchanged.

Default conservative fallback:

- maximum reconstruction strength: **0.42**;
- maximum dilation radius: **2 px**;
- maximum transition micro-smoothing: **0.08**.

New diagnostics include:

- `detailPreservation.eligible`;
- `gradientRetention`;
- `laplacianRetention`;
- `edgeRetention`;
- failed retention gates;
- `guardTriggered`;
- `fallbackAttempted`;
- `fallbackAccepted`;
- requested/applied strength.

A full rejection reports `reason: detail-preservation-reject` and returns an exact copy of the input frame data.

### 2. Empty-zone hard suppression cannot bypass preservation

File: `src/video/emptyZoneHardSuppress.js`

The two-pass hard smooth reconstruction now stops immediately if either internal smooth reconstruction activates the detail-preservation guard, falls back, or is rejected.

When this happens:

- the hard candidate is not accepted;
- the incoming image is returned unchanged;
- diagnostics report `reason: detail-preservation-guard`.

This prevents the stronger empty-zone path from reintroducing the scene5 regression after the normal smooth pass has already identified preservation risk.

### 3. More sensitive but still bounded coherent structured refinement

File: `src/video/structuredEvidenceRefine.js`

The shape-coherent micro pass was tuned for lower-amplitude residuals without raising the strength of the broad primary structured ring pass.

Default adjustments:

- shape alignment floor: **0.62 -> 0.58**;
- strength: **0.22 -> 0.24**;
- neighboring coherent residual floor: **0.85 -> 0.72**;
- per-pixel residual trigger: **1.25 -> 1.05**;
- full residual gate: **7.5 -> 6.5**;
- max luma delta: **9 -> 8.5**;
- blend cap: **0.24 -> 0.25**;
- minimum useful blend/shift slightly reduced so faint coherent evidence can produce a small correction.

Safety properties retained:

- correction must follow the alpha-shape orientation;
- both tangent neighbors must have a coherent residual sign;
- clean-anchor disagreement and tangent discontinuity still suppress edits;
- luma correction remains tightly bounded;
- this is a micro pass rather than a full-ROI repaint.

The evidence candidate's tone micro-pass is also slightly more local and lower amplitude:

- tone strength: **0.40**;
- max global shift: **5.5**;
- max local shift: **4.5**;
- local mix: **0.34**;
- tone trigger score: **0.72**.

### 4. Footprint-tapered local tone correction

File: `src/video/localToneMatch.js`

Changes:

- mismatch estimate now uses a **weighted median** of target residuals;
- removed the former hard minimum alpha-weight floor;
- target weight is now `alphaWeight * textureWeight` with a small acceptance floor only for excluding near-zero samples;
- strong footprint pixels carry more influence than weak feather pixels;
- a bounded local desired shift is blended with the robust global shift only when the local residual sign agrees with the global tone mismatch;
- sign-disagreeing samples are downweighted more strongly;
- post-clean global residual gates are slightly tighter.

New default local controls:

- `localMix`: **0.38**;
- `maxLocalShift`: **6**;
- minimum tone score: **1.05**;
- minimum accepted improvement: **0.03**.

New diagnostics include weighted sample support and mean local adaptation.

## Regression coverage

Added `tests/v1082Regression.test.mjs` with three release-specific synthetic regressions:

### scene5 analogue

Creates a background whose exterior is smooth enough for the smooth classifier, but contains low-contrast independent detail under the watermark footprint. The test requires the detail-preservation guard to trigger and reject the destructive smooth candidate, returning the source pixels unchanged.

### scene3 / scene7 analogue

Creates a smooth background with a stronger tone offset in the body and a smaller offset in the feather. The test requires:

- local tone correction to be accepted;
- tone mismatch to improve substantially;
- correction in the strong footprint to exceed correction in the feather, demonstrating footprint tapering rather than broad painting.

### scene1 / scene6 analogue

Creates a weaker continuous diamond-correlated structured residual. The test requires the coherent micro pass to detect and correct pixels while changing fewer than 16% of the synthetic ROI and keeping mean luma change below 3 levels.

## Local implementation validation before CI

Because the execution container cannot resolve GitHub hosts, repository cloning was not possible there. Source was read/written through the GitHub connector and isolated changed modules were syntax-checked and exercised in temporary local ESM harnesses.

Observed synthetic validation before committing:

- ordinary smooth-gradient case remained eligible for normal reconstruction;
- a scene5-like hidden-detail sample triggered the detail guard; the full candidate failed strongly and the conservative fallback was also rejected, preserving the exact incoming pixels;
- localized tone synthetic sample reduced the measured tone mismatch from approximately **8.06** to **2.09** while concentrating the edit on the stronger footprint;
- weak structured residual synthetic sample produced **52** coherent corrected pixels with mean absolute luma delta approximately **1.43**, indicating a bounded micro-correction rather than broad repainting.

These synthetic numbers are implementation checks only. They are not a claim that the real scene videos have been visually validated.

2. The real regression set must be rerun after merge, especially:
   - scene5: verify real detail is no longer erased;
   - scene1 and scene6: compare faint structured residual;
   - scene3 and scene7: compare local tone footprint;
   - previously-good scenes should be checked for no visual regression.

## Release acceptance rule

v1.0.82 should only be considered an improvement if **scene5 preservation is restored without materially regressing already-good samples**. A smaller watermark score alone is not sufficient when real scene detail is lost.
