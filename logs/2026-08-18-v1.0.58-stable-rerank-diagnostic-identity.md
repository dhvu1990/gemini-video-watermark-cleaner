# v1.0.58 stable rerank diagnostic identity

Date: 2026-08-18

## Goal
Make calibration rerank diagnostics stable when the selected candidate is copied or serialized before summarization.

## Problem
`selectedChangedFromBase` in v1.0.57 compared candidate object references. Two objects representing the exact same calibration identity could therefore be reported as different solely because they were separate JavaScript objects.

## Cause
The diagnostic layer used `selected !== baseWinner` instead of comparing the calibration identity fields already used to describe candidates.

## Changes
- Added `sameCandidateIdentity()` in `src/video/calibrationRerankDiagnostics.js`.
- `selectedChangedFromBase` now compares profile, shape scale, edge boost, edge gain, offsets and body gain.
- Added regression coverage where `selected` is a shallow copy of the base-winning candidate.
- Bumped package/app version to 1.0.58.

## Scope / safety
Diagnostic-only change.
- No calibration candidate generation changed.
- No rerank score changed.
- No near-tie threshold changed.
- No minimum coverage changed.
- No artifact weight changed.
- No cleanup strength changed.
- No pixel-restoration algorithm changed.
