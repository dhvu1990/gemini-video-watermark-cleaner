# v1.0.62 — Evidence-gated structured-ring refinement

Date: 2026-08-18

## Goal
Reduce the remaining shape-aligned diamond/ring residual on structured backgrounds without globally increasing cleanup strength.

## Cause
Earlier screenshot review showed that some cleaned outputs retain a thin diamond/ring outline. At the same time, structured backgrounds are vulnerable to over-cleaning and streak/paint artifacts. A global strength increase would therefore be too risky.

## Algorithm / logic
A new evidence-gated refinement stage reuses the existing structured-ring repair pass rather than introducing a second reconstruction system.

The refinement runs after the existing structured finishers and requires both evidence gates:
- aligned residual score >= 1.75 by default
- aligned sample density >= 0.012 of ROI pixels by default

Default refinement strength is 0.18 and is clamped to 0.08–0.30.

The candidate is accepted only when all safety conditions hold:
- corrected pixels > 0
- aligned residual improves by at least 1.5%
- aligned residual after <= 98.5% of before
- global residual total <= 100.2% of before
- luma residual <= 100.4% of before
- chroma residual <= 100.4% of before

Otherwise the candidate is rolled back completely.

The runtime diagnostic object records gate thresholds, density, before/candidate aligned metrics, before/candidate global metrics, candidate pixel count, and whether the candidate was accepted.

## Safety intent
- No global strength increase.
- No mask expansion.
- No calibration scoring change.
- No temporal atlas change.
- No duplicate repair system.
- The pass can only run when both residual score and residual density provide evidence.
- Unsafe or insufficiently beneficial candidates roll back.

## Tests
Added regression coverage for:
1. score/density gates keeping the refinement closed when evidence is insufficient;
2. forced gate eligibility producing an attempted candidate and enforcing the rollback/acceptance safety bounds.
