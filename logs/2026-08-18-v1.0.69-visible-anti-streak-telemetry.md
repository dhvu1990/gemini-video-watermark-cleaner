# v1.0.69 Visible Anti-Streak Telemetry

Date: 2026-08-18

## Goal

Expose the existing v1.0.68 anti-streak diagnostics directly in the user interface and export summary so real-video structured-background failures can be attributed before any further image-processing changes.

## Motivation

Seven user-supplied preview screenshots showed that v1.0.68 is already strong on near-black backgrounds and on preserving narrow bright lines crossing the watermark. The strongest remaining visual failures are structured brown/wood surfaces where the watermark body is removed but a low-frequency diamond/triangular tone/texture footprint remains.

The runtime already computes `preview.antiStreak`, but `src/main.js` previously dropped that field when serializing the detection payload into `detectResult`, so `calibration-ui.js` could not display it.

## Implementation

### Telemetry formatter

Added a pure helper that formats:
- temporal donor attempted / accepted / reason;
- donor guarded ratio, mean structure mismatch and residual ratio;
- atlas donor count, mean confidence and donor spread;
- structured attempted / accepted / accepted mode;
- structured aligned residual before/after, density and improvement;
- risk flags;
- export-level risk-frame and risk-flag counters.

The helper contains no DOM access and no image-processing logic.

### Preview wiring

`src/main.js` now includes `preview.antiStreak` in the serialized `detectResult` payload and emits a concise console diagnostic for advanced inspection.

### UI card

`index.html` adds a readonly `Anti-streak diagnostics` card. `src/calibration-ui.js` maps the formatter output into the card.

### Export summary

After processing, the result summary now includes:
- number of frames carrying at least one anti-streak risk flag;
- per-flag counts, sorted by frequency.

The export metadata itself is unchanged; the UI only formats fields already generated by the runtime.

## Pixel safety

v1.0.69 does not modify:
- `src/video/engine.js`
- `src/video/textureRepair.js`
- `src/video/multiFrameRepair.js`
- `src/video/structuredRingSuppress.js`
- donor strength or donor selection
- atlas thresholds
- structured cleanup thresholds
- calibration scoring
- masks
- stabilization strength
- any pixel-processing stage

Therefore this version is telemetry/UI-only and must not change cleaned pixel output.

## Tests

New formatter tests cover:
- non-empty high-risk preview telemetry formatting;
- stable empty-state formatting;
- export risk counters sorted by frequency.

Required CI gates:
1. Sync pinned alpha profiles
2. `npm run check`

4. `npm run build`

## Risk

The main risk is UI wiring drift: missing IDs, malformed formatting, or browser-side syntax errors. CI syntax/test/build gates must be green before merge.

## Merge condition

Merge only if all CI gates are green. If source/test fixes are required after CI failure, close the PR unmerged and move the correction to v1.0.70 according to the project version policy.
