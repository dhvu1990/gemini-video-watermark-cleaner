# v1.0.41 - Batch picker stability

## Problem
After v1.0.40, selecting multiple videos could leave the native file picker looking frozen while the page synchronously handled the returned FileList.

## Fix
- Snapshot the FileList immediately when the picker returns.
- Clear the hidden input before any queue work starts.
- Defer queue ingestion to a new task so the native picker can fully close first.
- Add files in chunks of 24 and yield to the browser between chunks.
- Add an `ingesting` state so batch controls cannot race while files are being added.
- Move retry resume into the batch UI itself so Retry directly requeues and restarts sequential processing.

## Scope
No watermark cleanup algorithm changes in this release.
