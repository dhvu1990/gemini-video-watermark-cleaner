# v1.0.24 — Structured Residual Ring Suppression

Date: 2026-08-15

## Motivation

Real-video validation of v1.0.23 confirmed two distinct operating regimes:

- the smooth USB-C sample is correctly classified as `smooth-rebuild` and becomes visually almost clean,
- the textured keyboard sample is correctly classified as `structured`, preserving real detail but still showing a thin residual Gemini diamond outline.

The remaining structured artifact is dominated by a narrow shape-aligned luma ring rather than broad color contamination. Increasing blur or full-footprint reconstruction on this case would risk destroying real keyboard edges and texture.

## Goal

Add one conservative final pass that is only eligible when the adaptive background classifier selected `structured`.

The pass must:

- target only the thin ring aligned with the Gemini alpha shape,
- protect real scene structure that crosses the watermark footprint,
- avoid global blur,
- preserve the existing `smooth-rebuild` result unchanged,
- try a candidate and automatically reject it when final residual quality does not improve.

## Implementation

### New module

`src/video/structuredRingSuppress.js`

The module exposes:

- `measureStructuredRingResidual()` — measures residual energy that is both inside the narrow watermark ring and directionally aligned with the alpha-map gradient,
- `applyStructuredResidualRingSuppression()` — builds a conservative candidate correction and accepts it only when measured quality improves.

### Shape-aligned targeting

For each candidate ring pixel:

1. compute the alpha-map gradient,
2. compute the local image luma gradient,
3. require meaningful alignment between the two,
4. find outer and inner color anchors along the alpha normal,
5. interpolate a bridge target,
6. correct mainly luma and only lightly correct chroma.

This makes the pass more likely to remove a residual Gemini outline than an unrelated keyboard edge.

### Structure guards

The pass is attenuated when:

- inner and outer anchors disagree strongly,
- tangent samples disagree strongly,
- the pixel belongs to the protected high-alpha core,
- alignment with the watermark shape is weak.

Maximum blend and per-pixel correction are intentionally lower than the primary edge bridge.

### Try-and-accept gate

Structured suppression is attempted when final structured residual remains significant.

Default triggers:

- total post-clean residual >= 0.80, or
- luma residual >= 1.35, or
- shape-aligned structured residual >= 1.40.

The candidate is accepted only when:

- it changes at least one eligible pixel,
- total residual or shape-aligned residual improves,
- total residual does not become materially worse,
- luma residual does not become materially worse.

If the candidate is rejected, v1.0.24 returns the exact pre-suppression image.

### Adaptive branch isolation

`applyDualRingLumaFinish()` now runs exactly one final adaptive branch:

- `smooth-rebuild` -> keep the v1.0.23 smooth reconstruction path; structured suppression is not called,
- `structured` -> optionally run structured residual ring suppression.

The final diagnostics are measured after whichever branch was actually selected.

## Regression coverage

New test file:

`tests/structuredRingSuppress.test.mjs`

Coverage includes:

1. a forced structured-ring candidate can never be accepted when materially worse,
2. low-residual structured content skips the pass,
3. smooth-rebuild mode does not run structured ring suppression.

The existing v1.0.23 smooth-background, temporal-mode, dual-ring, edge-bridge, detector, calibration, atlas and export regression suites remain active.
