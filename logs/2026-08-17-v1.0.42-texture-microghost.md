# v1.0.42 — Texture preservation + smooth micro-ghost cleanup

## Motivation
Recent real preview samples show two remaining failure modes:
- textured carpet/fabric backgrounds are cleaned but can look slightly smeared or too soft;
- very smooth bright backgrounds can retain an extremely faint Gemini diamond outline.

## Changes
- Shape ghost anchors now retain bounded local high-pass detail from clean pixels.
- When both clean anchors agree on texture, a small high-frequency component is reintroduced into the predicted luma target.
- Texture reinjection is reduced when image gradients align with the watermark shape, preventing reinforcement of the diamond itself.
- Added a low-amplitude micro-ghost path for very smooth backgrounds with strong anchor agreement.
- The micro path only activates on low-gradient fields and uses a lower residual threshold, but still must pass the same global luma/chroma/total residual safety gates.
- Added diagnostics for texture-restored pixels, micro-ghost pixels, and field smooth/texture confidence.
- Added regression tests for faint smooth backgrounds and textured structured backgrounds.

## Safety
No candidate is accepted unless shape residual improves and the existing global post-clean residual metrics remain within the established guard rails.
