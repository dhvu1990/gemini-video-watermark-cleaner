## Merged behavior

v1.0.71 adds a conservative final-output guard for validated accepted-structured-low-gain cases.

The guard does not restore the pre-ring image. It preserves the accepted primary/micro-salvage ring cleanup, replays a ring-only baseline only for eligible low-gain structured cases with downstream accepted finishers, compares the final downstream output against that ring baseline, and rolls back only the downstream finisher changes when aligned/global residual safety bounds are exceeded.

Default final safety envelope:
- aligned ratio <= 1.015
- total ratio <= 1.006
- luma ratio <= 1.010
- chroma ratio <= 1.012

The structured diagnostics now prefer final selected aligned residual measurements when available, so `Structured after` represents the actual final structured output rather than only the earlier ring-stage result.

When the guard rolls back downstream changes, anti-streak diagnostics include `structured-downstream-rollback`.
