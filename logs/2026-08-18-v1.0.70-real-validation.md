## Important follow-up discovery

Inspection after validation showed that `structuredRing.alignedAfter` currently represents the primary/micro-salvage ring result. Downstream accepted finishers such as Shape Ghost can modify the selected image afterward without recomputing the aligned structured-ring residual stored in `structuredRing.alignedAfter`.

Therefore the next behavior change must not blindly roll back the whole structured path using ring-only telemetry. The safe next step is a final-output guard that compares the post-finisher selected image with the pre-finisher ring-selected baseline and only rolls back downstream finishers when they materially worsen aligned/global residuals.

## v1.0.71 direction

- preserve ring-selected baseline;
- apply existing downstream finishers exactly as today;
- measure final aligned/global residual after downstream finishers;
- when a real accepted-low-gain ring case is present, guard the downstream changes;
- roll back only downstream finishers if final metrics materially worsen versus the ring-selected baseline;
- preserve the ring result itself;
- expose final guard diagnostics;
- add regression coverage for safe pass-through and downstream rollback behavior.
