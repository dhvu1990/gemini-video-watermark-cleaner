# v1.0.81 — Structured shape residual micro-refine

Date: 2026-08-20

## Objective

Improve the remaining recognizable Gemini/Veo diamond footprint on difficult structured backgrounds without globally increasing cleanup strength.

This release is driven by the latest seven-video real preview set supplied by the operator after v1.0.80.

## Real-preview benchmark observations

The supplied batch preview set showed a useful separation between successful and difficult cases:

- scene5: strongest result. Smooth background rebuild removed the mark cleanly and telemetry showed no risk flags.
- scene4: good result over a light/text-adjacent region. Real lettering and scene structure remained readable.
- scene2: good-to-fair result on green/black/high-contrast structure; only minor local tone difference remained.
- scene7: watermark body was removed but a dark/soft footprint remained, indicating local tone mismatch or over-smoothed footprint reconstruction.
- scene3: visible triangular/top residual remained; telemetry included `structured-downstream-rollback`, showing the safety system correctly rejected a worse downstream candidate but the safe baseline still retained residual structure.
- scene1: visible center spine plus top/diamond portions remained over horizontal structured lines.
- scene6: most difficult case; recognizable diagonal diamond outline and center structure remained after cleanup.

The difficult examples consistently correlate with telemetry such as:

- `dense-structured-ring-residual`
- `accepted-structured-low-gain`
- `high-contrast-adjacency`
- in one case `structured-downstream-rollback`

This is useful evidence that the diagnostic layer is tracking the actual visible failure mode.

## Design decision: do not raise global structured strength

A blanket strength increase was rejected for this release.

Reason:

The same batch includes scene4 and scene2, where real text and strong scene edges cross or sit close to the watermark region. Increasing the normal structured pass globally could improve scene6 while damaging text, real edges, or texture in the already-good cases.

Instead, v1.0.81 changes only the final evidence-gated structured refinement candidate.

## New module: `structuredEvidenceRefine.js`

Added `src/video/structuredEvidenceRefine.js`.

It introduces a narrow shape-coherent micro pass intended for residuals that still follow the watermark geometry after the normal structured pipeline.

### Shape-coherence requirement

A candidate pixel must first satisfy the existing type of alpha-gradient shape alignment evidence.

The micro pass then checks two nearby samples in both directions along the tangent of the watermark contour.

The center sample and both tangent neighbors must all have residuals with the same sign and sufficient magnitude.

This three-point continuity requirement is deliberately stricter than simply seeing one strong edge pixel.

A real isolated scene edge is therefore less likely to qualify than a continuous watermark-aligned residual contour.

### Anchor and tangent guards

For each candidate, the pass compares:

- clean/inner anchor disagreement across the alpha normal;
- local luma disagreement across the contour tangent.

Large disagreement suppresses the blend.

This is particularly important for scene4/scene2-type content, where letters or real object edges may overlap the watermark footprint.

### Correction policy

The shape-coherent pass:

- adjusts luma only;
- does not directly alter chroma;
- uses default strength `0.22`;
- clamps strength to `0.06..0.34`;
- caps local blend at `0.24`;
- caps the requested luma delta at `9`;
- requires a minimum residual before any pixel is changed.

This is intentionally a micro-refinement rather than another broad inpainting pass.

## Conservative tone micro-correction

After the shape-coherent candidate, the evidence-refinement path may run the existing local-tone matcher again with stricter/lower settings than the normal local-tone stage:

- strength: `0.42`
- max luma shift: `6`
- minimum mismatch score: `0.78`
- minimum improvement: `2.5%`
- minimum target samples: `12`
- minimum reference samples: `20`
- target gradient max: `9.5`
- reference gradient max: `10.5`

This is aimed at scene7/scene3-style localized dark/light footprint mismatch after shape cleanup.

The existing local-tone implementation still performs its own try/measure/accept checks before this micro tone result can become part of the refinement candidate.

## Final evidence gate remains strict

The new candidate replaces the previous behavior where evidence refinement simply ran another generic structured ring pass.

The outer acceptance gate is intentionally retained:

- candidate must change at least one eligible pixel;
- aligned residual improvement must be at least `1.5%`;
- aligned residual after candidate must be <= `98.5%` of before;
- global total residual may not exceed `100.2%` of before;
- global luma residual may not exceed `100.4%` of before;
- global chroma residual may not exceed `100.4%` of before.

If any gate fails, the candidate is discarded and the incoming pixels are returned unchanged.

## Integration

Updated `src/video/structuredRingSuppress.js`.

The existing structured order remains:

1. consensus repair;
2. primary structured ring pass;
3. optional micro-salvage;
4. shape ghost suppression;
5. center-seam suppression;
6. local-tone match;
7. outer-halo suppression;
8. evidence-gated refinement.

Only step 8 changed internally.

It now builds a candidate with `buildStructuredEvidenceCandidate(...)` instead of repeating `applyStructuredRingPass(...)`.

The evidence refinement still does not run when the primary structured gate itself was not triggered. This preserves the conservative behavior for easy/low-residual frames such as scene5.

## Diagnostics added to refinement state

The refinement state now records:

- `candidateMode`
- `candidatePixels`
- `coherentCandidates`
- `guardedPixels`
- `shapeCoherent`
- `toneMicro`
- `candidateAlignedImprovement`

Accepted output still uses the established `evidence-refine` accepted-mode suffix so existing diagnostic consumers remain compatible.

## Tests

2. the combined structured evidence candidate exposing shape/tone micro diagnostics;
3. invalid alpha geometry returning an exact no-op.

Existing `tests/structuredRingEvidenceRefinement.test.mjs` continues to verify the outer evidence gates and rollback behavior.
