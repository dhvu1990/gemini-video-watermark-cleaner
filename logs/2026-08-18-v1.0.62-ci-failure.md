## Failure
The failing regression was:
`structured ring suppression never accepts a materially worse candidate`

The assertion expected `acceptedMode` to be only one of:
- `primary`
- `micro-salvage`

v1.0.62 legitimately introduced an additional accepted suffix when the new evidence refinement is accepted, for example `primary+evidence-refine`. The dedicated evidence-refinement tests themselves passed.

## Root cause
The older ring-isolation test did not explicitly disable the newly introduced downstream evidence-refinement stage. Its accepted-mode assertion therefore became broader than the test's intended scope.
