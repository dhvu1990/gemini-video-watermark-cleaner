# v1.0.56 — calibration artifact minimum-coverage gate

Date: 2026-08-18
Branch: `agent/v1.0.56`
Baseline main: `440ccc623f6c1aaf376ebd988ac9018265e97cc6` (post-merge v1.0.55 record; application version v1.0.55)

## Objective

Prevent low-confidence artifact measurements from influencing calibration reranking. v1.0.55 already restricts artifact reranking to genuine base-score near ties, but the artifact penalty itself still applied whenever coverage was merely greater than zero.

## Problem found

`combineCalibrationArtifactScore()` accepted any positive artifact coverage. That means a candidate with only a very small measured portion of the watermark footprint could receive an artifact penalty even though the seam/tone/halo metric did not have enough spatial support to be trustworthy.

The original calibration-artifact design intent was conservative and coverage-aware. v1.0.56 restores that safety property explicitly.

## Implementation

Updated `src/video/calibrationRerank.js`:
- adds `minCoverage`, default `0.40`;
- artifact penalties are ignored when `coverage < minCoverage`;
- explicit `minCoverage: 0` is supported and does not fall back to the default;
- rerank diagnostics now expose `minCoverage`;
- each evaluated finalist exposes `artifactCoverageEligible`;
- the near-tie gate, top-N cap, deduplication, artifact weight, and relative penalty cap are unchanged.

The default sequence is now:
1. sort by existing primary calibration score;
2. deduplicate equivalent calibration identities;
3. exclude candidates outside the base-score near-tie gate;
4. evaluate at most the bounded top-N finalists;
5. ignore artifact metrics with coverage below 0.40;
6. apply the existing bounded artifact penalty only to sufficiently covered metrics.

## Tests

Updated `tests/calibrationRerank.test.mjs` with coverage for:
- zero coverage remains neutral;
- coverage `0.39` remains neutral under the default 0.40 threshold;
- coverage exactly `0.40` is eligible;
- `minCoverage: 0` explicitly disables the gate;
- a low-coverage artifact result cannot flip a near-tie candidate;
- diagnostics expose the effective minimum coverage.

Existing tests for bounded artifact influence, near-tie gating, top-N limits, and candidate deduplication remain in place.

## Scope / safety

Not changed in this version:
- primary calibration residual formula;
- body-gain search;
- profile / shape / edge candidate grids;
- subpixel search geometry;
- artifact weight (`0.055` default);
- artifact relative penalty cap (`10%` default);
- near-tie gate (`2%` relative and `0.20` absolute defaults);
- any image restoration or cleanup algorithm;
- structured/smooth routing or suppression thresholds.

This change can only reduce artifact-metric influence when measurement support is weak.
