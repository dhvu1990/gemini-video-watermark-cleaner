# v1.0.127 - Post-contour high-confidence body residual rescue

Fresh 8-video validation on 2026-09-10 showed that watermark localization remained stable at the same 72x72 Portrait 1080 inset, while several high-confidence scenes still retained a broad diamond-shaped interior/body ghost after the existing contour chain. Medium-confidence and scene-protected cases were already behaving conservatively and should not be made more aggressive.

## Change

- Keep the v1.0.126 persistent-contour implementation intact as `persistentContourSilhouetteDissolveCore.js`.
- Run a new `highConfidenceBodyResidualRescue` only after the existing persistent-contour core and only when the core still reports a strong residual.
- Require detection confidence >= 0.65, with reduced strength below 0.78.
- Reject the body pass when crossing-scene-edge risk is meaningful.
- Build body reconstruction from clean-alpha donor pairs in horizontal, vertical, and both diagonal directions.
- Require donor consensus, per-pixel scene-edge protection, local residual improvement, outline safety, bounded aggregate residual movement, and rollback on rejection.
- Preserve the 72x72 ROI and detector geometry; this release does not widen the cleanup region.
- Keep v1.0.126 contour acceptance modes unchanged when the contour core already accepted; body-rescue diagnostics are reported separately.

## Regression coverage

- Smooth high-confidence broad body residual can be reduced.
- Medium-confidence input remains blocked.
- Strong real scene edge crossing the watermark blocks the body pass.
- Runtime wrapper ordering is verified: contour core first, body residual rescue second.

Real-world validation policy remains fresh-batch only; prior user batches are not reused for visual retesting.
