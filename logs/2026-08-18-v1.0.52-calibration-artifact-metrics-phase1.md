## Context

The structured runtime now finishes with the following guarded sequence:

`Consensus -> Ring -> Micro-salvage -> Shape Ghost -> Center Seam -> Local Tone -> Outer Halo`

The cleanup pipeline can detect and repair three subtle artifacts that the existing alpha calibrator does not explicitly score:

1. narrow center seam / spine residual;
2. footprint-wide local luma/tone offset;
3. thin 1-2 px exterior halo immediately outside the nominal alpha footprint.

The current calibrator already scores residual buckets and background continuity. This phase intentionally does **not** alter calibration selection yet. It first provides one shared measurement layer for the three newly validated residual classes.

## Added

### `src/video/calibrationArtifactMetrics.js`

Exports `measureCalibrationArtifactResidual(image, alphaMap, options)`.

The measurement layer reuses the already-tested diagnostics from:

- `measureCenterSeamResidual`
- `measureLocalToneMismatch`
- `measureOuterHaloResidual`

It combines them using conservative default weights:

- Center Seam: 0.28
- Local Tone: 0.44
- Outer Halo: 0.28

Each component is confidence-weighted by its available sample count. Local Tone additionally requires reference-sample confidence. Missing/weakly sampled metrics therefore contribute less instead of appearing as a perfect zero.

Component scores are capped before aggregation to prevent one extreme local artifact from completely dominating future calibration ranking.

Returned diagnostics include:

- combined `score`
- measurement `coverage`
- `effectiveWeight`
- raw seam / tone / halo diagnostics
- per-component confidence, weight and weighted contribution

## Safety / scope

This phase is **measurement-only**:

- no pixels are changed;
- no alpha candidates are re-ranked yet;
- no global cleanup strength is changed;
- no runtime finisher behavior is changed;
- no extra calibration CPU cost is introduced in production yet.

The purpose is to validate metric behavior independently before wiring it into the calibrator.

## Tests

## Planned next phase if CI is green

Integrate this metric into `calibrateAlphaShape` only for a small top-N subset of coarse candidates. The existing residual/bucket score remains the primary first-stage filter. Artifact metrics should receive a light secondary weight and only participate when measurement coverage is sufficient.

This keeps CPU bounded and avoids letting a specialized metric override the established calibration score across every candidate.

No chroma-specific calibration weighting or broader alpha search should be added without new evidence.
