# v1.0.53 — Calibration top-N artifact rerank

Date: 2026-08-18
Baseline main: `6b125070a120a3d9cb0691c0b8a6be72984f62d4` (v1.0.52)

## Goal
Use the v1.0.52 measurement-only calibration artifact metrics as a light second-stage tie breaker without letting cleanup-specific signals dominate the established alpha calibration score or adding heavy CPU cost across the full search grid.

## Design
- Added `src/video/calibrationRerank.js`.
- The existing coarse + subpixel calibration score remains the primary ranking signal.
- Only the leading top-N candidates are evaluated with artifact metrics; default `topN = 4`, hard-capped at 6.
- Artifact contribution is coverage-aware and lightly weighted (`0.055` by default).
- Artifact penalty is capped to at most 10% of the candidate's existing selection score.
- Zero-coverage artifact measurements leave the base score unchanged.
- Tie breaking remains deterministic and falls back to the original selection score.

## Runtime calibration integration
`calibrateAlphaShape` now retains the coarse candidates and the 3x3 subpixel candidates, then optionally reranks only the leading subset.

Artifact evaluation uses the same calibrated alpha candidate and the same inverse-alpha + edge-polish output that is already relevant to cleanup. It measures:
- center seam residual,
- local tone mismatch,
- thin exterior halo.

The selected result exposes:
- `calibrationScore`,
- `artifactResidual`,
- `artifactRerank.topN`,
- compact per-finalist diagnostics.

The legacy `residualScore` remains the original calibration residual score so existing reporting semantics are preserved.

## Safety / performance controls
- No full-grid artifact scoring.
- No change to the alpha search ranges.
- No change to body-gain search.
- No change to cleanup runtime strengths.
- Artifact reranking can be disabled with `artifactRerank: false`.
- Artifact score cannot add more than 10% to the base selection score.

## Tests
Added `tests/calibrationRerank.test.mjs` covering:
1. hard relative penalty cap,
2. zero-coverage no-op behavior,
3. top-N-only evaluation and selection of a cleaner near-tie.
