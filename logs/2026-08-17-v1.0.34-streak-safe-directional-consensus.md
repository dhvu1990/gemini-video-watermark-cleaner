# v1.0.34 - Streak-safe directional consensus texture repair

Date: 2026-08-17

## Motivation

Real preview samples showed that the padded texture repair stage could occasionally leave directional smears or streak-like artifacts. The previous implementation selected a single lowest-cost horizontal/vertical/diagonal prediction for each watermark pixel. A locally plausible but scene-specific direction could therefore dominate the reconstruction.

## Change

`src/video/textureRepair.js` now uses a guarded directional consensus instead of blindly selecting one best direction:

- evaluates horizontal, vertical and both diagonal two-sided anchor predictions;
- prefers fully supported low-disagreement candidates;
- combines up to four directions with quality-weighted consensus;
- measures cross-direction spread and reduces blend strength when predictions disagree;
- requires stronger multi-direction support in protected high-alpha core pixels;
- lowers maximum padded-repair blend from 0.80 to 0.76 to reduce painted streaks;
- retains the existing hybrid edge/feather/core mask and temporal donor stage.

## Regression coverage

Added a synthetic test with one bright horizontal directional outlier while the other directions represent a darker background. The repair must improve the damaged watermark edge without copying the bright direction into a streak through the ROI.

## Scope

This release changes cleanup quality only. Detection geometry and alpha calibration are unchanged.
