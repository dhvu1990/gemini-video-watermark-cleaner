## Visual result

The visible watermark body is removed, but a broad low-frequency, shape-like/diamond footprint remains in the cleaned region. The residual is primarily tonal/structural rather than a sharp ring edge.

## Interpretation

The v1.0.71 downstream guard correctly did not roll back. The final downstream-selected output improved the aligned structured metric from the earlier ring-only result (1.635 in the previous validation) to 1.546, producing 10.1% aligned improvement from 1.720.

Therefore Shape Ghost/downstream finishers are not the main regression source for this sample according to the existing safety metrics. The remaining visible artifact is a metric blind spot: current aligned-ring/global residual metrics can improve substantially while a broad low-frequency diamond-shaped footprint remains perceptible.

`Risk flags = none` is consistent with the current implementation because final aligned improvement is no longer low-gain.

## Important metric limitation

`measureLocalToneMismatch()` is based on a robust plane fitted from clean surrounding samples and summarizes the target footprint using the median signed luma residual. On a structured region with a real material/tone boundary crossing the watermark, a single signed-median plane mismatch can under-represent spatially opposing residual lobes or cancel them. It is therefore not sufficient by itself as the next acceptance metric for this sample.

## Recommended v1.0.72 direction

Diagnostic-only spatial structured-footprint metric before any new behavior change.

The metric should target broad low-frequency residual energy that is correlated with watermark geometry while discounting genuine scene edges that continue through/outside the watermark region. Candidate design:
- low-pass luma before gradient analysis to suppress texture;
- compare low-frequency image-gradient orientation with alpha/watermark geometry across a wider body band, not just the thin ring;
- continuity guard using samples outside the footprint so real scene edges crossing the region are discounted;
- report score, sample coverage, shape-aligned density, and continuity-discounted score;
- no pixel changes in v1.0.72.

Synthetic regression coverage should include:
1. a broad diamond/shape-correlated tonal ghost that must score high;
2. a clean smooth region that must score low;
3. a genuine straight material boundary crossing the watermark region that should be discounted by continuity guard;
4. a textured structured background without shape-correlated residual that should remain low/moderate.

Only after real-video validation of this diagnostic should a later version use it for acceptance or targeted reconstruction.
