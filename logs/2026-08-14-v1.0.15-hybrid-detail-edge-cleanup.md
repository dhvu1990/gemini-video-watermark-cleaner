# v1.0.15 - Hybrid Detail-Preserving Edge Cleanup

Date: 2026-08-14

## Trigger

Real-video validation after v1.0.14 showed a quality regression compared with v1.0.12:

- v1.0.12 preserved visible background texture inside the Gemini watermark better, but the diamond outline remained too visible.
- v1.0.14 reduced the watermark more aggressively with multi-frame atlas reconstruction, but the cleaned region became visibly smeared/blurred and high-frequency keyboard texture inside the watermark was lost.

User requirement for this release:

> Combine both behaviors: preserve detail inside the watermark while processing the visible outer edge more aggressively.

## Root cause

v1.0.14 had two reconstruction stages that could modify the full watermark footprint:

1. `applyPaddedTextureRepair()` used a body-weight term that increased with alpha, so high-alpha center pixels received strong spatial interpolation.
2. `applyBackgroundAtlas()` used alpha strength as a positive blend gate, so high-confidence multi-frame donors could also replace the center of the watermark.

This meant the center could be averaged/interpolated more strongly than the edge, which is the opposite of the desired visual behavior for detailed backgrounds.

## Design decision

v1.0.15 introduces a soft three-region hybrid repair mask:

- **Core**: high-alpha interior. Keep inverse-alpha/calibrated Body gain as the dominant reconstruction. Spatial/temporal/atlas repair is almost disabled here.
- **Edge ring**: low-alpha + alpha-gradient boundary. Apply strong reconstruction here because this is where the visible Gemini outline remains.
- **Feather transition**: intermediate band between core and edge, allowing a smooth blend without a hard seam.

The mask is generated from:

- alpha magnitude;
- normalized alpha gradient;
- a low-alpha ring response;
- smoothstep transitions.

## Implementation

### `src/video/textureRepair.js`

Added `buildHybridRepairMask(alphaMap, width, height)` returning:

- `edge`
- `core`
- `feather`

Changed `applyPaddedTextureRepair()`:

- edge ring receives the dominant weight;
- feather receives moderate weight;
- core receives only a very small correction weight;
- existing anchor disagreement guard remains active.

Changed `applyTemporalDonorRepair()` with the same region weighting so a well-aligned donor cannot flatten the watermark core simply because motion confidence is high.

### `src/video/multiFrameRepair.js`

Added an atlas-specific hybrid alpha/gradient mask.

Changed `applyBackgroundAtlas()`:

- high-support/high-confidence donor consensus is still allowed;
- edge ring receives strong atlas blend;
- feather receives moderate blend;
- high-alpha core receives near-zero atlas blend;
- donor support and confidence thresholds from v1.0.14 remain intact.

### `src/video/engine.js`

Frame pipeline architecture remains the same. Export metadata is now tagged as v1.0.15 and includes:

- `hybridCoreRing: true`

### UI/package

- visible badge/title bumped to v1.0.15;
- Tune checkbox label changed to `Hybrid detail core + strong edge ring repair`;
- package version bumped to `1.0.15`.

## Regression tests

### Texture repair

Added tests requiring:

1. a damaged edge footprint moves closer to the synthetic background;
2. high-alpha core pixels remain close to the pre-repair detail-preserving reconstruction;
3. the hybrid mask classifies center pixels as core and boundary pixels as edge.

### Multi-frame atlas

Added a direct synthetic atlas test where:

- processed watermark pixels are intentionally dark;
- atlas donor pixels are intentionally bright;
- support/confidence are high everywhere;
- the edge pixel must change substantially more than the center pixel;
- the center pixel delta is bounded to remain small.

This test specifically prevents a future regression back to the v1.0.14 whole-footprint blur behavior.

## Scope deliberately unchanged

No change to:

- watermark catalog geometry;
- position detector;
- full-scan residual gate;
- alpha calibration candidate search;
- 14 px padded ROI;
- scene-cut reset;
- Web Worker architecture;
- MediaBunny/WebCodecs export;
- audio passthrough.

## Expected visual result

Compared with v1.0.14:

- more original/reconstructed texture should remain visible inside the watermark body;
- atlas/spatial repair should stop smearing the center;
- outer diamond outline should still receive stronger cleanup than v1.0.12;
- transitions between center and edge should remain soft rather than showing a hard ring.
