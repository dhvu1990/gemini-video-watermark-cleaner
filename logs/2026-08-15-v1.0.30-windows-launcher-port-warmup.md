# v1.0.30 - Windows launcher forwarded-port warmup fix

Date: 2026-08-15

## Real-world issue
After the v1.0.29 Desktop shortcut successfully started the private Codespace, the browser could still open the dynamic `*.app.github.dev` URL too early and receive HTTP 404. The Codespace state was already `Available`, but the GitHub forwarded-port proxy route for port 5173 had not finished warming up.

## Changes
- Bumped package/UI/worker metadata to v1.0.30.
- Increased forwarded-port timeout to 120 seconds.
- Require the same private `browseUrl` to be observed for 3 consecutive checks before it is considered stable.
- Added an 8-second proxy warmup delay after the stable checks before opening the browser.
- Reset stability tracking whenever port visibility needs to be changed or the port temporarily disappears.
- Installer browser authentication now uses `gh auth login --web --clipboard` so the GitHub device code is copied automatically.
- Added regression assertions for the stability/warmup behavior and clipboard auth.

## Security
- Repository remains private.
- Port 5173 must remain private.
- No PAT/token is embedded in launcher files.
- Video processing remains local in the browser.

## Algorithm scope
No detection, calibration, cleanup, reconstruction, or export algorithm changed in this release.
