# v1.0.43 — Guarded center-seam suppression

## Context

This release is based on `main` v1.0.42 (`c3452649c5330edd209e9a88faf5f03c362627ba`) and responds to the latest real preview review where several cleaned samples still retained a narrow center/spine-like residual inside the Gemini diamond footprint while other samples were already acceptably clean.

The goal is deliberately narrow: remove the remaining watermark-axis seam without increasing cleanup strength globally and without creating new streaks, blur, or damage to legitimate vertical scene structure.

## Observed failure modes from the latest review

The real preview set showed three useful classes:

1. Clean/control samples where the current pipeline already produces a good result.
2. Borderline samples with only a faint remaining diamond/axis footprint.
3. Hard structured/dark samples where a low-frequency diamond footprint or center seam remains visible.

The new pass is intended for classes 2 and 3 only. Class 1 is treated as a regression control and should normally be left unchanged by the acceptance gates.

## Design decisions

### 1. New `centerSeamSuppress.js`

Added a dedicated, conservative finisher instead of increasing ring or ghost suppression globally.

Main behavior:

- computes the watermark horizontal center from the alpha-map weighted centroid rather than assuming the image center;
- limits work to a narrow band around that alpha centroid (`halfWidth` default 3 px);
- only considers mid-alpha watermark-body pixels;
- searches for clean left/right anchors outside the alpha footprint;
- predicts the expected local color by interpolating those clean anchors;
- primarily corrects luma, with only a small bounded chroma adjustment;
- caps luma correction to 14 levels by default;
- never performs ROI-wide blur.

Default conservative parameters:

- `strength`: 0.55
- `halfWidth`: 3.0 px
- `maxRadius`: 30 px
- `maxLumaDelta`: 14
- `maxBlend`: 0.42
- `minScore`: 0.62
- `minImprovement`: 0.008

### 2. Persistent real-scene vertical-line guard

A center seam is dangerous to repair blindly because a legitimate vertical object edge can cross the watermark location.

The module therefore checks for matching vertical-line contrast in clean pixels above and below the watermark footprint. If the same line continues outside the alpha mask, the candidate is strongly suppressed.

This guard is designed to protect scene structures such as:

- door/window edges;
- poles;
- text strokes;
- vertical object boundaries;
- other persistent scene lines that happen to cross the watermark area.

### 3. Strict measure -> propose -> accept workflow

The pass first measures `centerSeam` residual, generates a candidate, measures again, and only accepts the candidate when all gates pass.

Acceptance requires:

- corrected candidate pixels exist;
- center-seam residual improves by at least 0.8% by default;
- center-seam score is at most 99.2% of the original;
- global post-clean total residual does not exceed 100.5% of the original;
- global luma residual does not exceed 100.8%;
- global chroma residual does not exceed 101.0%.

If any safety gate fails, the exact input pixels are returned.

### 4. Integration order

The structured finishing order is now:

1. structured directional consensus;
2. primary structured ring suppression or micro-salvage when eligible;
3. shape-ghost suppression;
4. center-seam suppression.

The seam pass therefore acts as a narrow final finisher after the broader shape-aware cleanup has already done its work.

It is also allowed to run when the main structured ring threshold is skipped, because a narrow center seam can remain even when the ring/global residual metrics are already low.

### 5. Diagnostics

`structuredRing.centerSeam` now exposes diagnostics including:

- enabled / attempted / accepted;
- before / after / candidateAfter seam metrics;
- outer residual before / after / candidateAfter;
- candidate and corrected pixel counts;
- guarded pixel counts;
- mean blend;
- mean absolute luma delta;
- candidate improvement.

`acceptedMode` now appends `+center-seam` when the new pass is accepted, or reports `center-seam` when it is the only accepted structured finisher.

## Tests added

Added `tests/centerSeamSuppress.test.mjs` with three regression scenarios:

1. Artificial central seam inside a soft diamond alpha footprint: candidate seam residual must improve; accepted output must remain bounded.
2. Persistent real vertical scene line crossing the watermark: the scene-line guard must activate and the pass must either reject the candidate or keep changes extremely small while satisfying global safety gates.
3. Structured pipeline integration: `structuredRing.centerSeam` diagnostics must always be exposed.

The existing test suite remains in place and will be used as the regression baseline for texture, dark structured ghost, smooth background, structured consensus, ring suppression, batch processing, download handling, and other prior behavior.

## Validation plan

Before merge, GitHub Actions CI must complete successfully with:

1. dependency installation;
2. pinned alpha synchronization;
3. `npm run check`;
4. complete `npm test` suite including the new center-seam tests;
5. Vite production build.

The release must not be reported as CI-green until the actual workflow result is observed.

## Real-video validation required after merge

CI validates logic and regressions but cannot prove visual quality on the original videos. After v1.0.43 is available, rerun the same real samples used in the review, especially:

- the two hard dark/structured footprint cases;
- one borderline faint-footprint case;
- at least one already-clean 720 Relocated control sample.

Success criteria:

- center/spine residual becomes less visible on the hard cases;
- already-clean controls remain visually unchanged or effectively unchanged;
- no new vertical smear, painted streak, or texture destruction appears.

## Deferred work

Local tone matching and outer-halo expansion are intentionally not included in this release. They remain possible follow-up work only if the v1.0.43 real-video retest shows that the center seam is improved but a broader low-frequency tone/halo mismatch still remains.

This keeps v1.0.43 focused, measurable, and easy to roll back if a real-scene regression is discovered.
