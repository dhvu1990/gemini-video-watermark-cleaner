# v1.0.64 — Temporal donor local-structure guard

Date: 2026-08-18

## Goal
Reduce overprocessing / streak / paint-like artifacts on structured backgrounds caused by a temporally aligned donor that is globally plausible but locally inconsistent at a specific pixel.

## Why this layer
Inspection of the three most likely sources of structured streak artifacts showed:
- `multiFrameRepair.js` temporal atlas already has donor-spread confidence suppression (v1.0.59).
- `applyPaddedTextureRepair()` already has directional consensus and spread guards.
- `structuredConsensusRepair.js` already has local-structure and spread guards.
- `applyTemporalDonorRepair()` in `textureRepair.js` still blended based on temporal shift confidence + region mask only, with no per-pixel local-structure agreement check.

Therefore v1.0.64 targets the single-frame temporal donor path rather than adding another reconstruction system or increasing cleanup strength.

## Algorithm / logic
A new local gradient comparison is applied before temporal donor blending:
1. Measure central-difference luma gradient around the processed pixel.
2. Measure the same gradient around the aligned donor pixel.
3. On nearly flat regions, leave donor confidence unchanged.
4. On structured regions, compare gradient orientation and magnitude.
5. Convert disagreement into a bounded structure confidence.
6. Multiply the existing temporal donor blend by that confidence.

Default guard characteristics:
- structure soft/hard magnitude range: 10 / 38 luma-gradient units;
- mismatch soft/hard range: 0.28 / 0.78;
- minimum structure confidence: 0.12;
- no change to the existing temporal shift minimum improvement (0.08), region mask, or base strength.

`structureGuard: false` is available only as an explicit compatibility/test override; default behavior is guarded.

## Diagnostics
The returned temporal donor result now exposes:
- `structureGuardEnabled`
- `candidatePixels`
- `correctedPixels`
- `guardedPixels`
- `meanStructureConfidence`
- `meanStructureMismatch`

## Regression test
Added a synthetic translated structured scene where the global shift remains valid but a small donor-exposed area contains a conflicting local stripe. The test compares guarded vs guard-disabled output and requires:
- correct temporal shift still detected;
- candidate pixels exist;
- at least one pixel is guarded;
- mean structure confidence drops below 1;
- guarded output deviates less from the clean processed structure than unguarded output.

Existing temporal-donor static-watermark skip test remains unchanged.

## Safety
- No global cleanup strength increase.
- No mask expansion.
- No calibration scoring change.
- No structured-ring threshold change.
- No temporal-atlas threshold change.
- Guard only reduces temporal-donor influence; it never increases it.
