## Why this release exists

Real cleaned-preview samples supplied after v1.0.42 show that the remaining visible watermark footprint is no longer dominated by the full Gemini body. The recurring failure mode is a thin vertical seam through the center of the diamond, sometimes accompanied by a faint outer contour or local tone mismatch.

v1.0.42 already contains structured directional consensus reconstruction, structured ring suppression, shape-ghost suppression, smooth micro-ghost cleanup, and texture reinjection. Therefore v1.0.43 does not replace those systems. The first phase adds a narrowly scoped, independently measurable center-seam finisher that can later be inserted after the existing structured cleanup stack.

## Phase 1 scope

This phase intentionally implements and tests the new center-seam module before wiring it into the runtime pipeline. This isolates algorithm quality from integration effects and gives CI a small regression surface.

## Algorithm design

### 1. Watermark-footprint geometry

The module derives the watermark center from the alpha footprint instead of assuming the center of the padded repair image. This matters because the runtime normally embeds the watermark alpha map inside a larger padded ROI.

The geometry estimator combines:

- the bounding-box center of alpha values above a low threshold;
- a smaller alpha-weighted centroid contribution.

The bounding-box center receives the higher weight so asymmetric alpha energy does not pull the seam axis too far from the true visual center.

### 2. Narrow center band

Only pixels within a configurable narrow band around the detected footprint center are eligible. Default half-width is `3.0` pixels.

Default eligible alpha range:

- minimum alpha: `0.055`
- maximum alpha: `0.70`

This prevents the new pass from becoming a general ROI blur.

### 3. Symmetric horizontal prediction

For each candidate seam pixel, the module samples symmetric left/right positions around the detected center axis. It searches radii from 2 to 7 pixels and selects the best pair using:

- left/right RGB disagreement;
- alpha symmetry;
- alpha agreement with the center pixel;
- a small distance penalty.

The predicted seam-free color is the mean of the selected symmetric pair.

### 4. Real-structure protection

A genuine vertical scene edge should have substantially different colors on the left and right sides. The module therefore rejects high-disagreement symmetric anchors and applies an additional local horizontal-gradient guard.

Default maximum anchor disagreement is `30` intensity levels on mean RGB difference.

This is the primary protection against flattening a real vertical object boundary that happens to cross the watermark center.

### 5. Residual measurement

`measureCenterSeamResidual()` reports:

- combined seam score;
- luma residual;
- chroma residual;
- sample count;
- detected footprint geometry.

The score is intentionally luma-heavy because the supplied real failures are primarily visible as brightness seams.

### 6. Candidate application

`applyCenterSeamSuppression()` follows the project's established candidate pattern:

1. measure the current seam residual;
2. skip if sample support or residual strength is too low;
3. generate a bounded candidate;
4. re-measure seam residual;
5. re-measure global post-clean residual;
6. accept only if the local seam improves without materially damaging global luma/chroma metrics.

Default correction limits:

- strength: `0.55`
- maximum luma delta: `14`
- maximum blend: `0.52`
- chroma correction is deliberately much weaker than luma correction.

## Acceptance gates

A candidate is accepted only when all of the following hold:

- at least one pixel was corrected;
- seam improvement is at least `0.8%` by default;
- candidate seam score is at most `99.2%` of the original seam score;
- global total residual is no worse than `+0.4%`;
- global luma residual is no worse than `+0.8%`;
- global chroma residual is no worse than `+1.0%`.

If any gate fails, the original image data is returned unchanged.

## Regression tests added

### Synthetic smooth-background seam

Creates a smooth gradient background with a Gemini-like diamond alpha footprint, then adds a narrow vertical brightness residual through the center. The test requires the candidate seam score to improve and, when accepted, requires the seam pixels to move closer to the known clean reference.

### Genuine vertical scene edge

Creates a strong real vertical luminance edge passing directly through the watermark center. The test verifies that the structure guard keeps output changes negligible.

### Invalid alpha geometry

Verifies that mismatched alpha dimensions are handled safely and return the original image unchanged.
