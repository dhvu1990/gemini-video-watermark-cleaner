# v1.0.113 — micro-interpolation local-band acceptance

## Real-video evidence
The v1.0.112 batch proves contour micro-interpolation can improve a real residual contour (scene7 accepted) while most other useful candidates are rolled back by the outline-wide `minImprovement` / `maxOutlineRatio` checks. Text/complex scenes remain protected and should not be made more aggressive.

## Goal
Accept a micro-interpolation candidate when the pixels actually touched by the narrow contour pass improve materially, even if the outline-wide metric changes only slightly, while preserving all existing global rollback limits and per-pixel scene protection.

## Changes
- measure interpolation-target residual before/after only on corrected pixels
- keep a normal outline-wide acceptance path, with a small finishing-pass relaxation
- add a separate local-band fallback that requires meaningful corrected-pixel improvement, no outline regression, low mean blend, and a bounded guarded-contour fraction
- keep global total/luma/chroma rollback thresholds unchanged
- keep hard scene guard, strength, max blend, max luma delta and ROI unchanged
- expose exact local-band acceptance/rejection diagnostics in batch preview

## Safety invariants
- no detector threshold reduction
- no Body/alpha gain increase
- no ROI expansion or full-area inpaint
- no stronger micro interpolation
- text/strong scene edges remain protected per pixel
- local-band fallback cannot accept an outline-wide regression
- global total/luma/chroma rollback remains mandatory

## Validation
Run syntax checks, full test suite and production build in CI. After deployment, compare the same batches used for v1.0.112, especially the prior accepted scene7 and text/complexity cases.
