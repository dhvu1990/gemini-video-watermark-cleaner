# v1.0.60 - Structured ring residual diagnostics

Date: 2026-08-18

## Goal
Add measurement-only diagnostics around the structured ring stage so future tuning can distinguish a high residual score caused by a dense shape-aligned ring from a sparse set of isolated pixels.

## Cause / motivation
The remaining screenshot evidence shows thin diamond/curved outline residuals after cleanup on several backgrounds. The existing structured-ring metric already reports a score and sample count, but there was no compact normalized summary for comparing sample support across ROI sizes or for correlating the ring stage with downstream shape-ghost, center-seam, local-tone and outer-halo finishers.

## Logic
`summarizeStructuredRingDiagnostics(structuredRing, pixelCount)` reports:
- structured-ring enabled/attempted/accepted state
- ring-specific acceptance and accepted mode
- aligned residual score before/after
- aligned residual sample count
- normalized aligned sample density (`samples / pixelCount`, clamped to 0..1)
- derived aligned improvement
- corrected/candidate pixel counts
- micro-salvage state
- compact states for consensus, shape ghost, center seam, local tone and outer halo.

The module does not alter any image data, thresholds, strength values, masks, acceptance gates or reconstruction logic.

## Tests
Added tests for:
1. Normal structured-ring diagnostics with known sample density and residual improvement.
2. Stable zero-value output when diagnostics input is absent.

## Safety scope
Diagnostic-only. No pixel-restoration behavior changes. No cleanup strength increase. No calibration or atlas behavior changes.
