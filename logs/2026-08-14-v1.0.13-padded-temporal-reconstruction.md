# v1.0.13 — Padded ROI + Temporal Donor Reconstruction

Date: 2026-08-14

## Trigger / real-video observation

Real-video testing on a 1080x1920 Gemini/Veo sample showed that v1.0.12 still left a clearly visible dark/blue diamond footprint after the white watermark body was removed.

Observed sample diagnostics:

- detection confidence: about 0.775 (77% match);
- position: x=864, y=1704, size=72;
- Body gain: 1.000;
- profile: `96-20260520`;
- shape scale: 1.000;
- Edge gain: 1.00;
- Edge boost: 0.055;
- Residual score: 22.817.

The quick scan had accepted this result using only three sampled frames even though the residual score was materially worse than the earlier ~13.6 sample. The cleaned ROI no longer looked like a white watermark, but the entire diamond footprint remained visible as a darker texture/color region.

## Decision

Do not continue increasing Edge gain, Edge boost or blur. Move the next quality tier to:

1. residual-gated quick-scan escalation;
2. padded ROI spatial texture reconstruction;
3. temporal donor reconstruction from prior raw frames when motion exposes clean background pixels;
4. fallback behavior that skips temporal donation when motion estimation is weak or the donor coordinate is still inside the watermark footprint.

## Quick-scan policy change

`QUICK_RESIDUAL_SCORE_LIMIT` is now 18.

A quick result is accepted only when all of the following are true:

- watermark detection passes;
- confidence passes the stricter quick threshold;
- vote ratio is at least 2/3 when available;
- calibration residual score is <= 18 when available.

The observed 22.817 sample therefore expands automatically to the configured full scan instead of being presented as a final quick result.

## Padded ROI reconstruction

Added `src/video/textureRepair.js`.

The export and preview paths now expand the 72x72 watermark ROI by 14 pixels on each available side. The padded region gives repair algorithms access to real clean texture outside the watermark footprint.

`applyPaddedTextureRepair()`:

- embeds the calibrated alpha mask into the padded ROI;
- finds clean alpha anchors along horizontal, vertical and diagonal axes;
- predicts the background through masked pixels from the most coherent anchor pair;
- prefers anchor pairs with low color disagreement and short distance;
- reduces repair strength when opposite anchors disagree strongly;
- supports limited one-sided repair when only one clean anchor is available;
- modifies only pixels inside the watermark alpha footprint.

## Temporal donor reconstruction

`estimateTemporalShift()` measures small translation between the clean padded-border texture of the current and previous frame using low-alpha pixels only.

`applyTemporalDonorRepair()` uses a previous-frame pixel only when:

- a non-zero shift improves border alignment by at least 8%;
- the shifted donor coordinate stays inside the previous padded ROI;
- the donor coordinate is outside the watermark alpha footprint (`alpha <= 0.008`).

This prevents using the same watermarked screen coordinate as a donor on static footage. When the background moves relative to the fixed Gemini overlay, previously covered target pixels can receive real texture from nearby clean coordinates in the previous frame.

## Preview/export consistency

Both detection preview and full export use the same padded reconstruction helper.

Preview:

- representative sampled frame is processed using a 14 px padded ROI;
- the previous sampled frame is supplied as an optional temporal donor;
- only the final 72x72 center is returned to `ZOOMED CLEANED`.

Export:

- every decoded frame crops the same padded ROI;
- inverse-alpha + existing edge cleanup runs on the 72x72 center;
- padded spatial texture repair runs next;
- temporal donor repair runs when the previous raw padded ROI provides a valid donor;
- temporal correction stabilization is then applied to the cleaned center;
- the repaired padded region is written back before AVC encode.
