## Objective

Make the calibration artifact rerank auditable without changing candidate selection behavior. v1.0.54–v1.0.56 added deduplication, a near-tie gate and a minimum-coverage gate; this version packages those decisions into one stable compact diagnostic object that can later be surfaced in the UI/worker logs.

## Implementation

Added `src/video/calibrationRerankDiagnostics.js` with `summarizeCalibrationRerank(reranked)`.

The summary exposes:
- top-N and candidate counts;
- duplicate removal count;
- near-tie eligible/excluded counts;
- configured relative/absolute gap limits;
- configured minimum artifact coverage;
- whether artifact reranking changed the selected candidate relative to the best base `selectionScore`;
- selected base score, final score and derived artifact penalty;
- selected artifact score / coverage / coverage eligibility;
- compact selected/base-winner calibration identities;
- compact per-finalist scores, penalty, coverage and identity.

## Important scope limit

This is diagnostic-only infrastructure.

It does **not**:
- change candidate ordering;
- change artifact scoring;
- change the 0.40 minimum coverage gate;
- change the 2% / 0.20 near-tie gate;
- change artifact weight or penalty cap;
- change pixel restoration or cleanup behavior;
- add runtime/UI output yet.

## Tests

Added `tests/calibrationRerankDiagnostics.test.mjs` covering:
