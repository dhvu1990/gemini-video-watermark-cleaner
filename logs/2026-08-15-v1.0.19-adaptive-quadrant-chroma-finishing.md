# v1.0.19 — Adaptive Quadrant Chroma Finishing

Date: 2026-08-15

## Context

Real-video validation of v1.0.18 showed the cleanup pipeline was already close to the target quality: core texture remained visible and the remaining Gemini artifact was mostly a very thin edge ghost. The pre-clean calibration diagnostics still reported a relatively high edge residual, but those values were measured before the final normal edge bridge and micro finishing pass, so they did not tell us how much cleanup the final passes actually achieved.

## Goals

1. Preserve the v1.0.18 core-detail behavior.
2. Measure residual artifact after the entire preview cleanup pipeline.
3. Separate final luma and chroma residual so color halos can be treated differently from brightness/detail.
4. Split the watermark into four quadrants and allow stronger finishing only where residual remains high.
5. Apply a conservative chroma-dominant final pass on the edge ring, with very small luma correction.
6. Keep structure guards and core protection so real keyboard/laptop edges are not flattened.

## Implementation

### Post-clean residual measurement

`src/video/edgeBridge.js` now exports `measurePostCleanupResidual()`.

The measurement:

- operates only on the narrow hybrid edge/feather region;
- ignores strongly protected core pixels;
- estimates a target value from the same outer/inner normal-direction anchors used by edge bridge;
- converts current and predicted colors into a Y/Cb/Cr-like representation;
- measures luma and chroma residual independently;
- records per-quadrant totals for top-left, top-right, bottom-left, and bottom-right.

The final total residual weights chroma more heavily than luma because the remaining real-video ghost is predominantly a faint blue/cyan edge rather than a large brightness error.

### Adaptive quadrant chroma finish

Added `applyAdaptiveQuadrantChromaFinish()`.

Rules:

- only runs on narrow edge-ring pixels;
- high-alpha core pixels are excluded;
- each quadrant receives a bounded strength adjustment based on its measured residual relative to the other quadrants;
- real structures are protected when inner/outer anchors disagree strongly;
- luma blend is intentionally capped much lower than chroma blend;
- luma correction is capped to ±14 intensity before blend;
- Cb/Cr correction is capped to ±24 before blend;
- maximum effective chroma blend is bounded so the pass cannot repaint the whole ROI.

### Pipeline order

The final edge pipeline is now:

1. normal-direction edge bridge;
2. micro edge finish;
3. post-clean residual measurement;
4. quadrant/chroma adaptive finishing;
5. post-clean residual measurement again.

The edge-bridge metadata records:

- `quadrantPixels`;
- `quadrantMeanChromaBlend`;
- `finalResidualBefore`;
- `finalResidualAfter`;
- `finalResidualImprovement`.

### UI diagnostics

`src/main.js` now includes final-cleanup diagnostics in the detection JSON payload.

The Tune panel adds a `Post-clean edge diagnostics` card showing:

- Final total residual;
- Final luma residual;
- Final chroma residual;
- Final improvement percentage.

This distinguishes calibration residual from the actually visible residual after the full preview cleanup pipeline.

## Regression tests

Updated `tests/edgeBridge.test.mjs` to verify:

1. normal edge bridge still reduces a dark diamond ring;
2. micro edge finish still improves a thin residual ring while preserving core detail;
3. synthetic cyan edge ghost is reduced by adaptive quadrant/chroma finishing;
4. the deliberately heavier top-right quadrant measures worse before cleanup;
5. post-clean chroma and total residual decrease after the adaptive finish;
6. mean core change remains below 0.75 intensity levels;
7. strong real structures still trigger protective behavior.

## Real-video validation target

For the same 1080x1920 keyboard/laptop sample used for v1.0.16–v1.0.18:

- core texture should remain as clear as v1.0.18;
- the thin cyan/blue Gemini outline should become less visible;
- `Final chroma residual` should be lower than the post-micro value;
- `Final improvement` should be positive;
- no broad blur or dark diamond footprint should reappear.
