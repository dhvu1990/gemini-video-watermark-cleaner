# v1.0.114 - contour safety-band interpolation rescue

## Real-video evidence
The latest two user-provided batches on v1.0.113 show that the watermark body is usually removed, but several cleaned previews still preserve a recognizable Gemini diamond as a faint border, dotted contour, halo, or texture/tone ghost. The most visible failures were batch-1 scene2/scene6/scene7 and batch-2 scene3/scene6/scene7/scene8.

## Root cause
The contour micro-interpolation stage previously operated only on pixels already inside the alpha footprint. Faint transition pixels just outside the alpha boundary could therefore survive. In addition, anchor lookup could select pixels too close to the residual edge, effectively feeding part of the watermark transition back into the interpolation.

## Changes
- add a canonical contour safety band around the detected alpha footprint
- use about 5 px normal expansion for a 72x72 ROI, scaled with the footprint size
- add extra expansion around the four Gemini tips
- build a synthetic guard-alpha map so anchors are forced outside the full safety band
- reuse that guard-alpha map for scene-edge protection inside the expanded band
- keep stronger reconstruction limited to low-alpha / external contour pixels; do not overwrite the high-alpha core that earlier stages already repaired
- add directional anchor consensus so structured backgrounds can continue through the former contour without isotropic blur
- add small chroma continuation in the safety band to reduce colored halos
- keep local-band and global rollback gates
- allow at most two bounded rescue passes; the second pass expands by +2 px only after the first pass was accepted
- expose safety-band radius, corrected-pixel count and rescue-pass diagnostics

## Safety invariants
- no detector threshold reduction
- no global Body gain increase
- no full-frame inpaint
- high-alpha core is not reprocessed by the safety-band pass
- scene-edge protection remains active using the expanded guard geometry
- global total/luma/chroma rollback limits remain mandatory
- maximum two rescue passes
- no blur-only replacement path

## Validation
CI must run syntax checks, the full test suite and production build. After deployment, re-run the same two real batches and compare the zoomed cleaned previews. Success requires the Gemini diamond to be visually unrecognizable while surrounding texture remains natural.
