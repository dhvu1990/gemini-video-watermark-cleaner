# v1.0.51 — Outer Halo Runtime Integration

Date: 2026-08-18

## Context

v1.0.50 introduced a standalone guarded Outer Halo suppressor and passed CI. Its purpose is to remove a very narrow 1–2 px watermark-shaped residual just outside the nominal alpha footprint without increasing global ring-cleanup strength.

PR #51 was merged after CI run #563 passed setup, syntax checks, tests and build. The merged main commit is `dfa0f4468e0c307259991ce9ca82f082fe334e80`.

## Goal

Wire the already-tested Outer Halo module into the real structured cleanup sequence only after all earlier structured finishers have had a chance to improve the footprint itself.

Runtime order after this change:

1. Structured consensus
2. Structured ring
3. Micro-salvage when eligible
4. Shape ghost suppression
5. Center seam suppression
6. Local tone match
7. Outer halo suppression

## Implementation

`src/video/structuredRingSuppress.js`

- imports `applyOuterHaloSuppression`
- adds `finishWithOuterHalo`
- respects explicit `outerHalo: false`
- forwards `outerHaloOptions`
- runs Outer Halo after Local Tone Match in both structured paths:
  - ring-threshold skip path
  - primary / micro-salvage path
- exposes diagnostics as `structuredRing.outerHalo`
- appends `+outer-halo` to `acceptedMode` only when the candidate is actually accepted
- includes accepted Outer Halo output in the final `structuredRing.accepted` state

No smooth-background rebuild path is changed.

## Test isolation

Older structured-ring tests had exact accepted-mode expectations intended to validate only the ring and micro-salvage stages. Because Outer Halo is now a later default finisher, those tests now explicitly disable later finishers using a shared isolation object:

- consensus: false
- shapeGhost: false
- centerSeam: false
- localToneMatch: false
- outerHalo: false

This prevents the same kind of unrelated accepted-mode regression previously seen when Center Seam and Local Tone Match were introduced.

## New runtime integration tests

`tests/outerHaloRuntimeIntegration.test.mjs`

Coverage:

1. A synthetic smooth background with a thin dark halo outside the alpha footprint runs through the structured runtime and must expose/accept Outer Halo diagnostics and append `outer-halo` to the mode.
2. Explicit `outerHalo: false` must preserve the opt-out contract and never append the mode suffix.

Earlier finishers are disabled in this integration fixture so the test specifically validates runtime placement and handoff rather than retesting each earlier algorithm.

## Safety constraints preserved

- no increase to global structured-ring strength
- no broad mask dilation
- no blur
- no chroma correction in Outer Halo Phase 1
- bounded luma-only shift
- strong reference-disagreement and tangent-structure guards
- try → measure → accept / exact rollback
- smooth-rebuild branch unchanged
