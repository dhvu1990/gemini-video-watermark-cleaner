# v1.0.36 - Guarded shape-aligned ghost suppression

Date: 2026-08-17

## Motivation

Recent real preview samples showed that detection was generally correct, but a faint Gemini diamond/triangle outline could remain after cleanup on structured backgrounds. v1.0.34 reduced directional streak/smear artifacts; v1.0.36 targets the remaining shape-aligned ghost without increasing cleanup aggressiveness globally.

## Changes

- Added `src/video/shapeGhostSuppress.js`.
- Measures residual inside the mid/high-alpha body using clean anchors on both sides of the alpha-gradient normal.
- Uses the watermark alpha-gradient geometry to distinguish a shape-aligned ghost from unrelated scene structure.
- Applies bounded luma correction plus very small chroma correction only when anchor disagreement, donor span, residual magnitude, and local structure guards are safe.
- Uses try-and-accept gating: the shape residual must improve while existing post-clean edge/luma/chroma metrics remain within strict non-regression limits.
- Integrated the pass after structured consensus/ring cleanup, including cases where the ring pass itself is skipped.
- Added diagnostics under `structuredRing.shapeGhost` and new acceptance modes such as `shape-ghost` and `primary+shape-ghost`.
- Added regression tests for a synthetic diamond ghost, high-detail scene protection, and structured-fallback metadata.
- Bumped package, worker metadata, and UI to v1.0.36.

## Scope

Detection, geometry selection, alpha calibration, export, and smooth-background hard suppression are unchanged. This release specifically targets residual visible shape outlines on structured-background fallback frames.

## Validation target

After CI passes and Pages deploys, retest the same real samples that previously showed faint diamond contours and compare `ZOOMED CLEANED` plus final MP4 output. Synthetic tests are safety coverage, not a substitute for real-video visual validation.
