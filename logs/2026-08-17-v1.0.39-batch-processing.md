# v1.0.39 — Sequential batch processing

## Goal
Allow multiple Gemini/Veo videos to be queued and cleaned without repeatedly selecting one file at a time.

## Changes
- Added a Batch Processing panel that mounts automatically above the single-file export section.
- Added multi-file selection and a visible queue with per-file status, progress, retry, remove, and download controls.
- Added sequential processing: one video is inspected and cleaned at a time to reduce browser RAM and GPU/decoder pressure.
- Added optional output-folder saving using the File System Access API when supported by the browser.
- Added two output naming modes:
  - `-cleaned.mp4`
  - original name for overwrite workflows (MP4 output remains `.mp4`).
- Added batch cancellation and retry support.
- Added reusable batch queue helpers and unit tests.
- Bumped the shared runtime/package version to v1.0.39.

## Safety / quality
- Batch mode reuses the same detection and cleanup settings as the existing single-file workflow.
- Cleanup algorithms are unchanged from v1.0.38.
- Files are processed sequentially rather than concurrently to avoid excessive memory consumption in the browser.
