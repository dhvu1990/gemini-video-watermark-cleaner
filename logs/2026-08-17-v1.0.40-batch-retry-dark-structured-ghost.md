# v1.0.40 - Batch retry + dark structured ghost cleanup

## User feedback
- Batch mode processes multiple videos successfully.
- Retry on a failed/cancelled item only requeued the item and did not actually start processing again.
- Real clean previews show very good removal on smooth light backgrounds, but structured/dark backgrounds can retain a faint Gemini diamond outline or diagonal ghost texture.

## Changes
- Added `batchRetryFix.js` so clicking Retry immediately resumes the batch after the existing UI requeues the failed item.
- Strengthened guarded shape-ghost cleanup only where watermark-shape alignment and clean-anchor agreement are strong.
- Added a bounded dark-background confidence boost, slightly higher blend ceiling, and slightly larger luma correction range.
- Kept the existing global residual acceptance gates; a candidate is rejected if total/luma/chroma residual becomes unsafe.
- Added regression tests for retry resume and dark structured ghost safety.
- Bumped shared runtime/package version to v1.0.40.

## Visual assessment of supplied samples
- Smooth pale-blue/white samples: cleanup is already strong; avoid making the global repair more aggressive.
- Blue structured sample: faint diagonal/diamond residual remains.
- Dark curved/black samples: most visible remaining issue is a low-contrast diamond ghost and local smudge; these are the main target of v1.0.40.
- High-contrast boundary sample: scene edge is mostly preserved, so changes remain guarded by shape alignment and global residual metrics.
