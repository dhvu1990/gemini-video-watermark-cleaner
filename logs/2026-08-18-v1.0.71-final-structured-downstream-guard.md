# v1.0.71 Final Structured Downstream Guard

Date: 2026-08-18

## Objective

Convert the validated v1.0.70 `accepted-structured-low-gain` diagnostic into a conservative runtime guard without rolling back the useful primary/micro-salvage ring cleanup.

## Real telemetry motivating the change

Validated structured sample:
- structured attempted: true
- structured accepted: true
- accepted mode: `primary+shape-ghost`
- aligned before: 1.720
- ring aligned after: 1.635
- residual density: 4.8%
- ring aligned improvement: 4.9%
- temporal donor / atlas inactive
- visible output still shows a low-frequency diamond footprint

## Follow-up architecture finding

`structuredRing.alignedAfter` was measured at the ring stage. Downstream finishers (Shape Ghost, Center Seam, Local Tone Match, Outer Halo and evidence refinement) could modify the final selected image afterward without recomputing that aligned residual. A whole-structured rollback based on ring-only telemetry would therefore be unsafe.

## Implementation

### New helper

`src/video/structuredDownstreamGuard.js`

The helper evaluates a final-output safety envelope only when all of the following are true:
- ring stage was accepted;
- at least one downstream finisher was accepted;
- aligned-before score >= 1.45;
- aligned sample density >= 3%;
- ring aligned improvement < 8%.

Default downstream safety limits relative to the replayed ring-only baseline:
- aligned residual ratio <= 1.015;
- global total ratio <= 1.006;
- luma ratio <= 1.010;
- chroma ratio <= 1.012.

The helper is decision-only and reports eligibility, rollback state, reason, failed gates and residual ratios.

### Runtime wiring

`src/video/dualRingFinish.js`

For normal structured cases the pipeline is unchanged.

Only for an eligible low-gain case with accepted downstream finishers:
1. keep the current full structured result;
2. replay the structured pass from the same structured input with Shape Ghost, Center Seam, Local Tone Match, Outer Halo and evidence refinement disabled;
3. measure the replayed ring-only baseline and the current final structured output;
4. evaluate the downstream safety envelope;
5. if unsafe, select the replayed ring-only baseline and discard only downstream finisher changes;
6. if safe, retain the full downstream result.

This preserves the useful ring cleanup and avoids rolling back to the pre-ring image.

### Final diagnostics

`src/video/structuredRingDiagnostics.js` now reports `alignedAfterScore` from the actual final selected structured output when downstream guard data is available. The summary also exposes downstream guard eligibility, rollback, reason, ratios, failed gates and rolled-back mode.

`src/video/antiStreakDiagnostics.js` emits `structured-downstream-rollback` when a rollback occurs and exposes the downstream guard block under structured diagnostics.

## Risk

Eligible low-gain cases may incur a second structured pass to reconstruct the ring-only baseline. This replay is deliberately limited to the narrow validated low-gain condition. The guard does not increase cleanup strength and cannot replace the accepted ring result with the pre-ring image.
