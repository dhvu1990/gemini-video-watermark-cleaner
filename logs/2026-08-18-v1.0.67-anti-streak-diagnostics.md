# v1.0.67 — Anti-streak diagnostic summary

Date: 2026-08-18

## Goal
Create one compact diagnostic summary for the anti-streak safeguards already present in the runtime, so future tuning can identify whether residual artifacts are more likely coming from temporal donor behavior, temporal atlas inconsistency, or structured cleanup.

## Why this version
After v1.0.64–v1.0.66, the runtime has multiple protections but their diagnostics are spread across separate objects. Adding more cleanup logic before consolidating those signals would make further tuning less evidence-based.

## Files changed
- `src/video/antiStreakDiagnostics.js`
- `tests/antiStreakDiagnostics.test.mjs`
- `package.json`
- `src/version.js`

## Summary inputs
- temporal donor acceptance diagnostics
- temporal donor local-structure diagnostics
- temporal atlas summary
- structured-ring diagnostics summary

## Summary outputs
### Temporal donor
- attempted / accepted / rejected
- reason
- total / luma / chroma residual ratios
- candidate / corrected / guarded pixels
- guarded pixel ratio
- mean local-structure confidence and mismatch

### Atlas
- donor count
- supported pixels
- mean confidence
- mean donor spread
- masked-donor mode

### Structured cleanup
- attempted / accepted / acceptedMode
- aligned ring score before / after
- aligned sample density and improvement
- accepted state of consensus, shape ghost, center seam, local tone and outer halo

### Risk flags
Diagnostic-only flags include:
- `temporal-donor-rejected`
- `temporal-donor-structure-guard-active`
- `high-donor-spread`
- `dense-structured-ring-residual`
- `structured-cleanup-low-gain`

These flags do not alter repair behavior.

## Safety
- No pixel modifications.
- No cleanup strength changes.
- No threshold or mask changes in the repair pipeline.
- No temporal donor selection changes.
- No atlas selection changes.
- No structured cleanup acceptance changes.

## Tests
Added synthetic coverage for:
1. combined high-risk diagnostics producing the expected ordered risk flags;
2. empty diagnostics producing a stable zero/quiet summary with no NaN values and no risk flags.
