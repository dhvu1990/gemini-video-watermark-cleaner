# v1.0.29 - Windows One-Click Private Codespaces Launcher

Date: 2026-08-15

## Goal

Remove the remaining daily friction from the private deployment. The user should no longer need to remember whether the Codespace is stopped, manually visit GitHub Codespaces, or keep a hard-coded `*.app.github.dev` URL.

## Baseline

Private migration was completed on v1.0.28:

- repository is private;
- Codespaces works on GitHub Free;
- port 5173 is private;
- `.devcontainer/start-vite.sh` auto-starts Vite after a container rebuild;
- local health check returns HTTP 200;
- the private forwarded URL opens the cleaner;
- video analysis and cleanup work end-to-end in Codespaces.

## v1.0.29 changes

### Windows launcher

Added `tools/windows/GeminiCleaner.ps1`.

The launcher:

1. requires an authenticated GitHub CLI session;
2. discovers Codespaces dynamically by repository instead of hard-coding the current Codespace name;
3. selects the most recently used Codespace;
4. calls `POST /user/codespaces/{name}/start` when the Codespace is not already Available/Starting;
5. polls the Codespace API until state becomes `Available`;
6. polls Codespaces port metadata for source port 5173;
7. enforces private port visibility when necessary;
8. reads the live `browseUrl` from GitHub CLI and opens it in the default browser;
9. opens the GitHub Codespaces page as a troubleshooting fallback on failure.

The launcher never embeds a PAT, GitHub token, Codespace name, or `app.github.dev` URL.

### Windows installer

Added `tools/windows/Install-GeminiCleaner.ps1` and `GeminiCleaner.cmd`.

The installer:

- detects GitHub CLI;
- installs it with `winget` if necessary;
- uses GitHub browser authentication when needed;
- explicitly refreshes the stored OAuth credentials with the `codespace` scope;
- copies launcher files to `%LOCALAPPDATA%\GeminiVideoWatermarkCleaner`;
- creates a Desktop shortcut named `Gemini Video Watermark Cleaner`.

### Version synchronization

- package version bumped to 1.0.29;
- worker export metadata bumped to 1.0.29;
- `calibration-ui.js` now updates the static HTML title and first visible badge at runtime, eliminating the old v1.0.26 display mismatch without rewriting the large index file.

### Tests

Added `tests/windows-launcher.test.mjs` to verify:

- repository-based Codespace discovery;
- no hard-coded Codespace URL/name;
- official start endpoint is present;
- state polling waits for `Available`;
- port 5173 is dynamically discovered;
- private visibility is enforced;
- dynamic `browseUrl` is opened;
- installer uses GitHub CLI authentication rather than embedded tokens;
- visible runtime version is synchronized to v1.0.29.

## Security model

The final daily-use path remains:

Windows shortcut -> authenticated GitHub CLI -> private Codespace -> private forwarded port 5173 -> local browser processing.

The repository remains private and no backend service is introduced.

## Validation plan

1. CI: install dependencies, alpha setup, syntax checks, all tests, production build.
2. Install the Windows package on the user's Windows workstation.
3. Stop the existing Codespace.
4. Double-click the Desktop shortcut.
5. Confirm the launcher starts the Codespace automatically.
6. Confirm port 5173 is private and the browser opens the live URL.
7. Process one Gemini/Veo regression video.
8. Record final confirmation in Google Drive deployment journal.
