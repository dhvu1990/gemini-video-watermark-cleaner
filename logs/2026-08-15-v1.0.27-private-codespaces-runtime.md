# v1.0.27 — Private Codespaces Runtime

Date: 2026-08-15

## Purpose

Prepare the project for the selected private-use architecture:

- GitHub Free
- Private repository
- GitHub Codespaces
- Private forwarded port
- no separate backend server

This release is an infrastructure/privacy milestone. It does not intentionally change watermark detection, calibration, cleanup, background classification, structured repair, empty-zone hard suppression, export quality, or video processing behavior from v1.0.26.

## Architecture decision

The project will stop relying on a public GitHub Pages URL for personal use after the private migration is complete.

Target runtime:

```text
Private repo
  -> Codespace
  -> Vite 0.0.0.0:5173
  -> Private forwarded port
  -> owner-authenticated browser
```

The app remains browser/local-first. The Codespace serves the application source/bundle, while the selected video and cleanup processing remain in the user's browser runtime.
