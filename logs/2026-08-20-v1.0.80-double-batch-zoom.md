# v1.0.80 — Double-size batch zoom previews

Date: 2026-08-20

## Request

In `Process multiple videos`, enlarge the per-video `ZOOMED ORIGINAL` and `ZOOMED CLEANED` preview cards to approximately twice their previous size so watermark-removal quality is easier to judge visually.

The v1.0.79 batch preview cards were intentionally compact:

- preview grid column: 92px;
- displayed canvas: 78 x 78px.

On real multi-video review this was too small for inspecting remaining diamond edges, local texture distortion, and subtle cleanup artifacts.

## Change

Updated `src/batch-mount.js`.

Desktop/tablet preview sizing is now:

- preview grid column: 184px;
- displayed canvas: 156 x 156px;
- card spacing increased slightly from 8px to 12px;
- detection/preview gap increased from 14px to 18px.

This is an exact 2x increase for the two primary preview dimensions requested by the user:

- 92 -> 184px;
- 78 -> 156px.

The underlying preview ImageData is unchanged. This release enlarges display size only; it does not rerun cleanup at a different internal resolution.

## Responsive behavior

At viewport widths below 1100px, the detection information and zoom cards stack vertically so the larger preview pair does not squeeze the detection summary.

At widths below 760px:

- the two preview cards share the available row width;
- canvases use `width: 100%` and `aspect-ratio: 1/1`;
- fixed 184px columns are not forced onto narrow screens.

## Safety

No changes were made to:

- watermark detection;
- alpha calibration;
- structured cleanup;
- smooth cleanup;
- temporal donor repair;
- output encoding;
- batch worker retry behavior;
- cached batch detection behavior.

This release is UI-only apart from version/test/journal updates.

## Tests

Added `tests/batchZoomSize.test.mjs` covering:

1. desktop zoom columns are 184px;
2. displayed canvases are 156 x 156px;
3. mobile layout remains responsive and does not force fixed 184px columns.

Existing batch Auto Detect tests continue to cover that every video receives separate `ZOOMED ORIGINAL` and `ZOOMED CLEANED` canvases.
