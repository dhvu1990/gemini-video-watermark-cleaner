## Objective
Make the artifact reranker act strictly as a near-tie refinement instead of allowing a visually cleaner artifact metric to overturn a calibration candidate that is already clearly worse according to the existing primary calibration score.

This follows the conservative design principle established in v1.0.52-v1.0.54: the legacy calibration score remains the dominant signal; center seam, local tone and outer-halo measurements are secondary diagnostics/refinement only.

## Problem found
After v1.0.54, candidate deduplication protects the small top-N budget, but top-N selection alone is not sufficient protection. A candidate may still enter the top-N while being meaningfully worse than the base winner. Because the artifact penalty can add up to a bounded percentage of the base score, an unusually high artifact residual on the best base candidate could allow a clearly worse base candidate to win.

That behavior is undesirable because the artifact measurements are intentionally partial and confidence-weighted. They should resolve near ties, not replace the calibrated alpha-fit objective.

## Implementation

### `src/video/calibrationRerank.js`
Added a near-tie eligibility gate after deduplication and before top-N slicing.

Default eligibility limits:
- maximum relative base-score gap: `2%`
- maximum absolute base-score gap: `0.20`

A candidate must satisfy both limits relative to the best unique candidate. Candidates outside this band are never artifact-evaluated and therefore cannot be promoted by artifact scoring.

The existing protections remain unchanged:
- deduplicate calibration identities first
- top-N default remains 4 with hard cap 6
- artifact contribution remains coverage-aware
- artifact penalty remains capped by `maxRelativePenalty`
- zero artifact coverage leaves the base score unchanged

New rerank diagnostics:
- `eligibleCount`
- `excludedByGap`
- `bestSelectionScore`
- `maxRelativeGap`
- `maxAbsoluteGap`

### `src/video/calibration.js`
Added optional calibrator parameters:
- `artifactMaxRelativeGap = 0.02`
- `artifactMaxAbsoluteGap = 0.20`

These values are forwarded to `rerankCalibrationCandidates` and recorded in the returned `artifactRerank` diagnostics together with input/unique/duplicate/eligible counts.

No primary candidate score, body-gain search, coarse grid, subpixel search, restoration pixel operation, or runtime cleanup threshold was changed.

## Tests
Updated `tests/calibrationRerank.test.mjs`.

Coverage now includes:
1. artifact contribution remains capped relative to base calibration score;
2. zero coverage leaves base ordering unchanged;
3. near-tie candidates can still be artifact-reranked;
4. duplicate calibration identities do not consume top-N slots;
5. a clearly worse base candidate is excluded before artifact evaluation, even if it would have an ideal artifact score.

The final regression specifically uses a base winner at `10.00` and a clearly worse candidate at `10.30`. With default limits, only the base winner is evaluated; the worse candidate cannot be promoted by artifact metrics.

## Safety / scope exclusions
This version intentionally does NOT:
- increase artifact weight;
- increase artifact penalty cap;
- alter the primary calibration residual formula;
- add artifact scoring to the full 54-candidate coarse grid;
- change body-gain selection;
- change subpixel search offsets or offset penalty;
- change Center Seam / Local Tone / Outer Halo suppressor thresholds;
- change smooth-vs-structured cleanup routing;
- change pixel restoration or finishing strength.

## Expected benefit
The calibration artifact reranker becomes a true secondary near-tie discriminator. This reduces the risk of choosing an inferior alpha registration merely because one partial artifact metric happens to be lower, while preserving the ability to prefer cleaner candidates when their primary calibration scores are genuinely close.
