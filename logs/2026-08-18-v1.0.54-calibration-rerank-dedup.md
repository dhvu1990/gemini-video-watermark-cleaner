# v1.0.54 - Calibration rerank finalist deduplication

## Context

v1.0.53 introduced bounded top-N artifact reranking after the primary calibration score. During post-merge review, the calibration candidate list was found to contain a deterministic duplicate: the coarse winner and the subpixel `(offsetX=0, offsetY=0)` candidate can describe the exact same calibration identity.

Because the reranker evaluates only a small top-N subset, a duplicate can consume one of those expensive artifact-evaluation slots without adding diversity. That reduces the effective search breadth and can make the second-stage reranker less useful, especially when `topN=4`.

## Objective

Ensure top-N artifact reranking evaluates unique calibration identities while preserving the original primary ranking and all existing bounded artifact penalties.

## Implementation

Updated `src/video/calibrationRerank.js`:

- Added a calibration identity key derived from:
  - `profile`
  - `shapeScale`
  - `edgeBoost`
  - `edgeGain`
  - `offsetX`
  - `offsetY`
  - `bodyGain`
- Optional explicit `candidateKey` is supported for future callers.
- Generic test candidates without calibration identity fields remain distinct, so existing generic rerank behavior is preserved.
- Candidates are still sorted by `selectionScore` first; deduplication therefore keeps the best-scoring representative of each identity.
- Top-N is taken after deduplication, so duplicate candidates no longer consume artifact-evaluation slots.
- Result diagnostics now include:
  - `inputCount`
  - `uniqueCount`
  - `duplicateCount`
- Existing artifact scoring behavior is unchanged:
  - default top-N stays 4
  - hard cap stays 6
  - artifact weight stays bounded
  - max relative penalty stays 10% in calibration integration
  - zero coverage leaves the base score unchanged.

## Tests

Updated `tests/calibrationRerank.test.mjs` with a regression case that reproduces the coarse-best vs subpixel-center duplicate and verifies:

- only one of the duplicate identities is artifact-evaluated;
- the freed slot is used by the next unique candidate;
- input/unique/duplicate diagnostics are correct;
- existing near-tie reranking behavior remains covered.

## Safety / scope

This version does not modify restoration pixels, cleanup strengths, alpha profile generation, artifact metrics, or the base calibration score. It only improves finalist diversity before the already-bounded second-stage artifact evaluation.
