# v1.0.107 - Partial scene-protected outline rescue

Date: 2026-08-29
Branch: `fix/partial-scene-outline-rescue-v1.0.107`
Base main: `92ab520ffb6e053ae3902d34f9228c78fb087c46` (v1.0.106)

## Real-video evidence

A fresh seven-scene portrait batch still shows a recognizable Gemini/Veo diamond residual in multiple cleaned previews. The strongest cases are scene1 and scene3; scene4 and scene6 combine a remaining diamond contour with genuine crossing scene structure. scene2, scene5 and scene7 are improved but retain lower/right or central ghost contours.

The repeated diagnostic pattern is `final-visual-watermark-residual` together with `post-chain-outline-scene-protected`. This indicates that v1.0.106 export-calibration parity is no longer the primary bottleneck. The current limiting behavior is the global crossing-scene-edge eligibility gate in outline residual escalation.

## Root cause

`applyOutlineResidualEscalation()` already uses `sceneEdgeProtectionAt()` for every candidate pixel and skips strongly protected scene-edge pixels. However, the earlier eligibility stage disabled the entire outline pass whenever `measureCrossingSceneEdgeRisk()` marked the ROI unsafe. A single genuine line crossing the watermark could therefore protect the whole remaining diamond, including large contour sections far away from the real line.

## Change

Add a conservative `partial-protected` scene mode:

- keep the existing full-safe path unchanged;
- if the global crossing-edge gate is unsafe, allow a partial pass only when watermark-outline evidence is stronger than normal and scene-edge coverage remains localized;
- preserve the existing contour-wide scene guard;
- use stricter per-pixel scene-edge rejection in partial mode;
- cap strength, blend and luma delta below the normal outline pass;
- keep dense/complex crossing structure fully blocked;
- retain post-candidate residual and global artifact acceptance checks.

No detector thresholds, alpha/body gain, ROI size or generic whole-region reconstruction are increased.

## Expected effect

This change is aimed primarily at scenes where a real line crosses only part of the watermark ROI. It should clean the unprotected portions of the diamond while leaving the genuine scene line substantially unchanged. Smooth scenes continue to use the normal full-safe outline path.

## Validation

Regression coverage adds:

- normal smooth-scene path remains `full`;
- localized crossing structure may enter `partial-protected` mode and produce candidate corrections;
- crossing-line luma movement remains tightly bounded;
- dense crossing structure fails partial eligibility and remains blocked.

CI plus a fresh real-video batch is required before merge. Visual success must not be declared from synthetic tests alone.
