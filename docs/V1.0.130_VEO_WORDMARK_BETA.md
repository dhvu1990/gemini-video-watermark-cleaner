# v1.0.130 - Veo text watermark beta checkpoint

## Deployment intent

This release is an **operator-requested beta deployed to the existing GitHub Pages URL for real-video testing**. It is not a claim of visual cleanup quality. The application version is sourced from `package.json` and `src/version.js`. The hero, page title, feature badge and footer use the shared version constant where JS is active.

## Changes

- Add an independently gated Veo **text wordmark** profile and multi-frame corner candidate search, without weakening the existing Gemini diamond safety threshold.
- Use a separate, bounded wordmark alpha reconstruction pass with donor-consistency and protected-scene-edge acceptance rather than running the Gemini diamond-specific chain over the text.
- Route detected watermark type through preview, single export, batch export and the worker's calibration cache.
- Add a manual watermark-type selector (automatic, Gemini diamond, Veo text beta) with a square ROI override.
- Add a prominent version display and "Veo text (beta)" label so the operator can verify which build is loaded.
- Add unit/regression tests and include the new source module in the syntax-check script.

## Safety and scope

- Visible watermark overlays only; no invisible provenance/SynthID work.
- Local media processing; no source video is committed or uploaded by the application.
- Keep the existing scene-cut temporal reset, Gemini calibration path and background reconstruction implementation unchanged.
- The text template is an **initial approximation based on a small operator-supplied cropped image**, not a fitted alpha calibration from raw source frames.

## Validation / operator handoff

- GitHub Actions runs `npm run setup:alpha`, `npm run check`, `npm test`, `npm run build`. Record the final passing job and GitHub Pages deployment when merging.
- **Real Veo source/output validation is pending.** A small watermark crop was available but not a full source video; synthetic unit tests do not prove accurate text restoration.
- In test videos check: correct detected wordmark location, original vs cleaned zoom, missed glyph pixels, white/dark remnants, synthetic color blotches, scene edges/text crossing the ROI, temporal flicker, and export/preview parity.
- If confidence is low, use the explicit manual type selector rather than lowering global thresholds.
- If results regress, stop applying that candidate and record a reproducible failure class for a bounded follow-up release.
