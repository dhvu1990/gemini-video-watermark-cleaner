# v1.0.129 Temporal Background Atlas

This phase upgrades the existing multi-frame atlas from a mostly edge/ring finisher into a source-aware temporal reconstruction layer.

## Core behavior

- Motion alignment uses a coarse-to-fine translation search so a wider exposure window remains practical.
- The atlas keeps two donor channels:
  - legacy cleaned/masked donor consensus, aligned only inside the caller-requested motion window for backward compatibility;
  - observed clean-exposure donors, allowed to search a wider motion window and sampled only where motion moves the requested scene pixel outside the fixed watermark alpha footprint.
- Observed donors receive independent support, consistency, motion/alignment confidence and spread telemetry.
- When at least two consistent observed donors exist, temporal reconstruction is allowed to reach the high-alpha core instead of only polishing the watermark ring.
- Static frames that never expose the hidden background do not get synthetic observed coverage; they fall back to the existing conservative spatial/structured pipeline.
- Existing legacy atlas behavior remains unchanged when observed clean exposure is unavailable.

## Safety

- Requires multi-frame donor agreement for full-core replacement.
- Uses median donor color and median-absolute-deviation rejection to suppress transient outliers.
- Uses an alpha safety radius so pixels immediately adjacent to the watermark edge are not treated as genuine clean observations.
- The wider observed search has its own minimum-improvement gate; it does not change the legacy alignment used by existing cleanup passes.
- Two-donor core reconstruction has a lower blend cap than three-or-more-donor reconstruction.
- Existing downstream residual, contour and scene-structure safety passes remain active.

## Diagnostics

`summarizeAtlas()` exposes legacy and observed search radii, observed support, observed core coverage, mean observed confidence/spread and whether the temporal observed atlas is available. `applyBackgroundAtlas()` also reports how many observed and observed-core pixels were actually reconstructed.
